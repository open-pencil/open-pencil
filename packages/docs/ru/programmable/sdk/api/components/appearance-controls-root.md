# AppearanceControlsRoot

`AppearanceControlsRoot` передаёт через слоты набор данных и действий `useAppearance()`. Он подходит для переиспользуемых элементов управления внешним видом с собственным оформлением.

Компонент сам вычисляет представление текущего выделения, в том числе `showIndependentCorners`. Оно включается, если объект явно использует независимые углы или импортированный объект содержит разные радиусы при устаревшем признаке общего радиуса. Интерфейс должен использовать это значение, а не хранить отдельный локальный `ref`.

`cornerSmoothingPercent` представляет нормализованное значение SceneGraph в диапазоне `0…100` или как `MIXED`. Действия над углами принимают нормализованные значения `0…1`.

Переключение независимых углов для нескольких объектов, изменение сглаживания и сохранение отдельных радиусов объединяются в одну запись истории отмены. Исходное значение каждого объекта сохраняется.
