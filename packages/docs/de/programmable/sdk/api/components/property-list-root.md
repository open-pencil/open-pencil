# PropertyListRoot

`PropertyListRoot` koordiniert Eigenschaften, die als Array gespeichert werden. Elemente und gemischter Zustand werden über Eigenschaften übergeben; Änderungen werden als Ereignisse ausgegeben.

Der Slot stellt Aktionen zum Hinzufügen, Entfernen, Ersetzen, teilweisen Aktualisieren und Ändern der Sichtbarkeit bereit.
