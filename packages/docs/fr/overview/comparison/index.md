# Alternatives à Figma comparées

Les équipes quittent Figma pour des raisons différentes : posséder leurs fichiers, travailler hors ligne ou sous Linux, héberger leur propre serveur, choisir leur IA ou cesser de payer par siège. Les outils ci-dessous répondent à ces besoins de manières différentes. Ce tableau reflète la documentation de chaque produit en novembre 2026 ; suivez les liens pour des comparaisons détaillées.

## À quoi sert chacun

- **OpenPencil** est un éditeur de design qui continue de travailler avec les fichiers Figma : il ouvre et enregistre les `.fig`, fonctionne hors ligne sur toutes les plateformes de bureau et est conçu pour être piloté par l’IA et par des scripts. Cloud est facultatif et auto-hébergeable.
- **[Penpot](./penpot)** est la plateforme de design open source la plus établie : web, avec son propre format, du prototypage et un serveur que vous pouvez héberger.
- **[Lunacy](./lunacy)** est un éditeur de bureau gratuit et propriétaire d’Icons8, avec une grande bibliothèque graphique intégrée.
- **[Grida](https://grida.co)** est un canevas open source pour le design, les images et les présentations, encore au début de son développement.
- **[Graphite](https://graphite.art)** est un éditeur vectoriel et matriciel open source bâti sur un graphe de nœuds, pour l’illustration et les graphismes procéduraux plutôt que le design d’interface.
- **[Quant-UX](https://quant-ux.com)** est un outil open source de prototypage et de tests d’utilisabilité.
- **[Pencil](./pencil)** et **[Paper](./paper)** sont des outils de design commerciaux conçus pour travailler avec des agents de code IA.
