# toolCursor

`toolCursor(tool, override?)` gibt den CSS-Cursor für ein Werkzeug zurück. `override` kann das Ergebnis ersetzen.

Die Funktion sorgt in einer eigenen Arbeitsfläche oder Werkzeugleiste für einheitliche Cursor.
