- Designs save themselves, as in Figma. Every design lives in a library on the device and saves itself about a second after each edit, so there is no Save, no unsaved-changes dot, and closing a design asks nothing. Opening a file adds a copy to the library and leaves the file as it was. File → Save Local Copy… writes the design to a `.fig` file, in place of Save, Save As…, Save to Storage…, and Autosave, and ⌘S saves at once. Once S3 storage is set up, the library syncs to it, the designs saved before included. The start page lists the library as Figma's Recents, with where it is saved, and Open Storage Workspace… is gone, since the home button opens it. Double-click a tab to rename its design. Right-click a design on the start page to open it or move it to the trash; the trash, next to Recents, restores designs or deletes them permanently, one at a time or with Empty trash, after a warning.
- The library syncs designs to S3 storage as versions: a design's content is stored once under its content hash, with a small manifest per version and a head naming the current one. An open design reaches storage at most every 30 seconds and at once when it closes or the page is hidden, and a rename, trash, or restore uploads no content. The trash syncs between devices. When two devices change the same design, the library keeps both, and this device's version becomes "(conflicted copy)". Designs stored in the earlier layout keep working and move to the new one on their next save. Slide decks in the bucket are listed with a Deck label and can be trashed, restored, deleted, or downloaded as a `.deck` file, but not opened.
