# Навигация по холсту

Холст — это неограниченная рабочая область. Перемещайтесь по ней и меняйте масштаб, чтобы работать с разными частями макета.

## Перемещение по холсту

Чтобы сдвинуть видимую область, не перемещая объекты:

- удерживайте <kbd>Space</kbd> и перетаскивайте холст;
- перетаскивайте холст средней кнопкой мыши;
- проведите двумя пальцами по сенсорной панели.

## Инструмент «Рука»

Нажмите <kbd>H</kbd>, чтобы включить инструмент «Рука». Пока он активен, любое перетаскивание по холсту перемещает видимую область — удерживать <kbd>Space</kbd> не нужно.

Чтобы выйти из этого режима, выберите другой инструмент, например нажмите <kbd>V</kbd> для инструмента «Выделение».

## Масштаб

Масштабирование выполняется относительно положения указателя:

- <kbd>Ctrl</kbd> + прокрутка, либо <kbd>⌘</kbd> + прокрутка в macOS;
- жест сведения пальцев на сенсорной панели;
- сочетания клавиш из таблицы ниже.

На панелях слоёв и свойств жест сведения пальцев заблокирован, чтобы он случайно не изменил масштаб всей страницы в браузере.

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Переместить видимую область | <kbd>Space</kbd> + перетаскивание | <kbd>Space</kbd> + перетаскивание |
| Инструмент «Рука» | <kbd>H</kbd> | <kbd>H</kbd> |
| Увеличить масштаб | <kbd>⌘</kbd><kbd>+</kbd> | <kbd>Ctrl</kbd> + <kbd>+</kbd> |
| Уменьшить масштаб | <kbd>⌘</kbd><kbd>−</kbd> | <kbd>Ctrl</kbd> + <kbd>−</kbd> |
| Масштаб 100% | <kbd>⌘</kbd><kbd>0</kbd> | <kbd>Ctrl</kbd> + <kbd>0</kbd> |
| Вписать документ | <kbd>⌘</kbd><kbd>1</kbd> | <kbd>Ctrl</kbd> + <kbd>1</kbd> |
| Масштаб по выделению | <kbd>⌘</kbd><kbd>2</kbd> | <kbd>Ctrl</kbd> + <kbd>2</kbd> |

## Советы

- Перед масштабированием наведите указатель на область, которую хотите рассмотреть.
- Инструмент «Рука» остаётся активным до выбора другого инструмента.
- О работе с объектами рассказывается в разделе [Выделение и преобразование](./selection-and-manipulation).
