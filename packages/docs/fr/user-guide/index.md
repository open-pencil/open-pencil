# Guide d’utilisation

Comment concevoir dans OpenPencil, regroupé selon ce que vous voulez faire. Vous débutez ? Commencez par [Premiers pas](/fr/getting-started).

::: tip Raccourcis
Certaines pages affichent les raccourcis de votre clavier, que vous pouvez changer en bas de la barre latérale. Les autres utilisent les touches Mac : <kbd>⌘</kbd> correspond à <kbd>Ctrl</kbd> sous Windows et Linux, <kbd>⌥</kbd> à <kbd>Alt</kbd> et <kbd>⇧</kbd> à <kbd>Shift</kbd>.
:::
