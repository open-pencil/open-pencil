# FontPickerRoot

`FontPickerRoot` fournit un sélecteur avec une liste asynchrone de familles et une recherche. Il utilise Reka UI Combobox, mais permet de remplacer le bouton, le champ de recherche, les éléments, l’indicateur de sélection et l’état vide par des emplacements.
