# Aprire e salvare

OpenPencil apre e salva i file `.fig`, lo stesso formato usato da Figma. Apre anche pagine web e i file `.pen` di pen.dev.

## Aprire un documento

Premi <Keys mac="⌘ O" other="Ctrl O" /> e scegli un file, oppure trascinalo sulla finestra. Si apre in una nuova scheda.

## Aprire una pagina web

<GuideLegend>

<GuideImage name="files/open-url" alt="La finestra Apri da URL con un indirizzo e tre dimensioni di finestra" />

1. Scegli **File → Apri da URL…**.
2. Inserisci l’indirizzo.
3. Scegli la dimensione di finestra per cui è impaginata la pagina.
4. Fai clic su **Apri**.

</GuideLegend>

La pagina diventa un insieme di livelli che puoi modificare. Un indirizzo può anche portare a un’immagine o a un file di design.

L’app desktop apre qualsiasi indirizzo ed esegue prima gli script della pagina. Se si ferma a un banner dei cookie o a una pagina di accesso, disattiva **Esegui gli script della pagina**. Nel browser si possono aprire solo i siti che lo consentono, e i loro script non vengono eseguiti.

Per interrompere, chiudi la scheda.

## Aggiungere un file al design

Scegli **File → Inserisci…**, oppure trascina il file sulla tela. Puoi inserire immagini, file SVG e pagine HTML.

## Salvare

- **Salva** con <Keys mac="⌘ S" other="Ctrl S" /> aggiorna il file che hai aperto. I browser che non possono scrivere sui tuoi file, come Firefox e Safari, lo scaricano invece.
- **Salva con nome…** con <Keys mac="⇧ ⌘ S" other="Ctrl Shift S" /> ti permette di scegliere un nuovo nome o una nuova posizione.

I file in altri formati, come `.pen`, vengono salvati come nuovo file `.fig`, e l’originale resta com’era. I file salvati si aprono in Figma.

## Ridurre le dimensioni di un file

1. Fai clic su una parte vuota della tela, così che non sia selezionato nulla.
2. Nel pannello Design, cerca **Documento**.
3. Scegli **Ridotta** o **Minima**.

I file più piccoli richiedono più tempo per il salvataggio. **Veloce** salva come fa Figma, e Figma apre tutte e tre le varianti.

## Recuperare il lavoro non salvato

OpenPencil conserva una copia dei documenti che non hai mai salvato su file, anche dopo che ne hai chiuso le schede. La pagina iniziale le elenca in **Lavoro non salvato**: aprine una per continuare a lavorarci, o scegli **Scarta** per eliminare la copia.

Le copie restano su questo computer, in questo browser o in questa app, e non sostituiscono il salvataggio. Per smettere di conservarle, disattiva **Conserva automaticamente il lavoro non salvato** in **Impostazioni → Generali → Ripristino**.
