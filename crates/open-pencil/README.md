# open-pencil

The Rust crates of [OpenPencil](https://github.com/open-pencil/open-pencil), an open-source
design editor, in one place.

| Module | Crate | What it does |
| --- | --- | --- |
| `open_pencil::fig` | [`open-pencil-fig`](https://crates.io/crates/open-pencil-fig) | Reads Figma `.fig` files: the archive, its records, and pages with their instances expanded. |

Depend on the crate a module re-exports to take only that part.
