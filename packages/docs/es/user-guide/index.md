# Guía de usuario

Cómo diseñar en OpenPencil, agrupado según lo que quieras hacer. ¿Es tu primera vez? Empieza por [Primeros pasos](/es/getting-started).

::: tip Atajos
Algunas páginas muestran los atajos de tu teclado, que puedes cambiar al final de la barra lateral. Las demás usan las teclas del Mac: <kbd>⌘</kbd> es <kbd>Ctrl</kbd> en Windows y Linux, <kbd>⌥</kbd> es <kbd>Alt</kbd> y <kbd>⇧</kbd> es <kbd>Shift</kbd>.
:::
