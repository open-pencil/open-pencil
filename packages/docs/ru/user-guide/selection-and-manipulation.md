# Выделение и преобразование

Выделите один или несколько объектов, чтобы перемещать, изменять размер, поворачивать, копировать и менять порядок наложения.

## Выделение

- Щёлкните объект, чтобы выделить только его.
- Удерживайте <kbd>Shift</kbd> и щёлкайте объекты, чтобы добавлять их к выделению или удалять из него.
- Начните перетаскивание на пустом участке холста, чтобы создать прямоугольную область выделения. После отпускания кнопки будут выделены все пересекающиеся объекты.
- Нажмите <kbd>⌘</kbd><kbd>A</kbd> или <kbd>Ctrl</kbd> + <kbd>A</kbd>, чтобы выделить все объекты текущей страницы.
- Щёлкните пустой участок холста, чтобы снять выделение.

## Перемещение

- Перетащите любой выделенный объект. Все остальные выделенные объекты переместятся вместе с ним.
- Клавиши со стрелками сдвигают выделение на 1 пиксель.
- <kbd>Shift</kbd> + стрелка сдвигает его на 10 пикселей.

## Размер

Вокруг выделения отображаются восемь маркеров: четыре по углам и четыре по сторонам. Перетащите маркер, чтобы изменить размер.

Удерживайте <kbd>Shift</kbd> при перетаскивании углового маркера, чтобы сохранить пропорции.

## Поворот

Наведите указатель немного дальше углового маркера. Когда появится указатель поворота, начните перетаскивание.

Удерживайте <kbd>Shift</kbd>, чтобы привязывать угол к шагу 15°.

## Копирование

- <kbd>⌥</kbd> + перетаскивание в macOS или <kbd>Alt</kbd> + перетаскивание в Windows и Linux создаёт копию и сразу перемещает её.
- <kbd>⌘</kbd><kbd>D</kbd> или <kbd>Ctrl</kbd> + <kbd>D</kbd> создаёт копию на том же месте.

## Удаление

Нажмите <kbd>Backspace</kbd> или <kbd>Delete</kbd>, чтобы удалить все выделенные объекты.

## Порядок наложения

Порядок меняется внутри общего родительского объекта:

- <kbd>]</kbd> — поместить поверх остальных соседних объектов;
- <kbd>[</kbd> — поместить позади остальных соседних объектов.

## Видимость и блокировка

- <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> или <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>H</kbd> скрывает или показывает выделенные объекты. Скрытые объекты остаются в дереве слоёв.
- <kbd>⇧</kbd><kbd>⌘</kbd><kbd>L</kbd> или <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>L</kbd> блокирует или разблокирует выделенные объекты. Заблокированный объект нельзя выбрать или переместить на холсте.

## Перемещение на другую страницу

Выберите целевую страницу через [контекстное меню](./context-menu). Она станет новым родителем перемещаемых объектов.

## Секции

При рисовании секции все пересекающиеся соседние объекты автоматически становятся её дочерними элементами.

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Выделить всё | <kbd>⌘</kbd><kbd>A</kbd> | <kbd>Ctrl</kbd> + <kbd>A</kbd> |
| Создать копию | <kbd>⌘</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Создать и переместить копию | <kbd>⌥</kbd> + перетаскивание | <kbd>Alt</kbd> + перетаскивание |
| Удалить | <kbd>⌫</kbd> / <kbd>Delete</kbd> | <kbd>Backspace</kbd> / <kbd>Delete</kbd> |
| Сдвинуть на 1 пиксель | Стрелки | Стрелки |
| Сдвинуть на 10 пикселей | <kbd>⇧</kbd> + стрелка | <kbd>Shift</kbd> + стрелка |
| Поверх остальных | <kbd>]</kbd> | <kbd>]</kbd> |
| Позади остальных | <kbd>[</kbd> | <kbd>[</kbd> |
| Скрыть или показать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>H</kbd> |
| Заблокировать или разблокировать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>L</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>L</kbd> |

## Советы

- Если объекты перекрываются, выбирайте их и меняйте порядок на панели [Слои и страницы](./layers-and-pages).
- Группировка, создание компонентов и другие действия находятся в [контекстном меню](./context-menu).
