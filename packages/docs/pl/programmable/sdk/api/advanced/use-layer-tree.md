# useLayerTree

`useLayerTree()` zwraca kontekst najbliższego `LayerTreeRoot`.

Użyj composable we własnych komponentach potomnych wymagających elementów drzewa, zaznaczenia, rozwiniętych gałęzi lub działań wierszy.
