# Экспорт

Сохраните слой в файл или скопируйте его прямо в другое приложение. Чтобы позже продолжить работу над дизайном, лучше [сохраните документ](./files).

## Экспортировать слой

1. Выделите один или несколько слоёв. Если ничего не выделено, экспортируется страница.
2. На панели «Дизайн» нажмите **+** рядом с **Экспорт**.
3. Выберите размер и формат.
4. Нажмите **Экспорт**.

<GuideLegend>

<GuideImage name="exporting/panel" alt="Настройки экспорта с четырьмя пронумерованными элементами" />

1. **Масштаб** задаёт размер изображения. Выберите вариант из списка или введите свой, например `2.5`.
2. **Формат экспорта** задаёт тип файла.
3. **Экспорт** сохраняет каждую строку в файл. Несколько файлов приходят одним ZIP-архивом.
4. **Предпросмотр** показывает, что получится.

</GuideLegend>

Чтобы получить слой в нескольких размерах, снова нажмите **+**. Каждая новая строка удваивает масштаб предыдущей.

## Выбрать формат

| Для чего | Формат |
| --- | --- |
| Скриншоты и изображения с прозрачностью | PNG |
| Фотографии, где прозрачность не важна | JPG |
| Более лёгкие изображения для веба | WEBP |
| Иконки и иллюстрации, которые остаются чёткими в любом размере | SVG |
| Печать и отправка страниц | PDF |
| Презентации | PPTX |
| Диаграммы | draw.io |

Масштаб применяется только к PNG, JPG и WEBP.

**Файл → Экспорт выделения…** также сохраняет файл `.fig`, в котором есть только выделенные слои.

## Скопировать в другое приложение

Щёлкните слой правой кнопкой и выберите **Копировать/Вставить как**.

<GuideLegend>

<GuideImage name="exporting/copy-as" other="exporting/copy-as-other" alt="Меню «Копировать/Вставить как»" />

- **Копировать как PNG** — для чатов и документов. Сочетание: <Keys mac="⇧ ⌘ C" other="Ctrl Shift C" />.
- **Копировать как SVG** — для кода и векторных редакторов.
- **Копировать как JSX** — для кода.
- **Копировать как текст** копирует текст текстового слоя.

</GuideLegend>
