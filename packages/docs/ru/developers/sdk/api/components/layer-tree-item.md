# LayerTreeItem

`LayerTreeItem` представляет строку дерева слоёв. Слот по умолчанию получает состояние и действия для выделения, раскрытия дочерних объектов, видимости, блокировки и переименования.

Приложение может отобразить собственную разметку строки, сохранив поведение SDK.
