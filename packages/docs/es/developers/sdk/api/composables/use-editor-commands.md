# useEditorCommands

`useEditorCommands()` proporciona los comandos disponibles, sus etiquetas y atajos, la comprobación de disponibilidad y una función para ejecutarlos.

Use el registro compartido para que barras, menús contextuales y menús de aplicación muestren los mismos atajos y respeten las mismas reglas.
