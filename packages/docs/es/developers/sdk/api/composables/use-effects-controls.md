# useEffectsControls

`useEffectsControls()` proporciona:

- efectos actuales y estado mixto;
- efecto predeterminado;
- acciones para añadir, eliminar, sustituir y actualizar;
- cambio de visibilidad;
- tipos de sombra y desenfoque admitidos.
