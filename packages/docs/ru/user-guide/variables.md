# Переменные

Переменные хранят повторно используемые токены дизайна: цвета, интервалы и другие значения, которые можно связать со свойствами объектов. После изменения переменной все связанные объекты обновляются.

## Открытие редактора переменных

Снимите выделение со всех объектов. На вкладке «Дизайн» появятся свойства страницы, включая раздел «Переменные». Нажмите значок настроек, чтобы открыть диалог.

## Коллекции

Переменные объединяются в коллекции. Каждая коллекция представлена отдельной вкладкой.

- Щёлкните вкладку, чтобы перейти к коллекции.
- Дважды щёлкните её имя, чтобы переименовать коллекцию.

## Режимы

Коллекция может содержать несколько режимов, например Light и Dark. В таблице каждый режим занимает отдельный столбец, а переменная хранит значение для каждого режима.

### Добавление коллекций и режимов

Новая коллекция создаётся на панели инструментов диалога. Режимы позволяют хранить варианты темы или значения для разных контрольных точек адаптивного макета.

## Работа с переменными

В таблице есть изменяемый по ширине столбец «Имя» и по одному столбцу для каждого режима.

- **Создать:** нажмите **Создать переменную**.
- **Переименовать:** щёлкните ячейку с именем.
- **Изменить значение:** щёлкните ячейку нужного режима.
- **Найти:** введите часть имени в поле поиска.

### Цветовые переменные

Для цветовой переменной в таблице отображается поле цвета. Щёлкните образец, чтобы открыть выбор цвета.

Типы `FLOAT`, `STRING` и `BOOLEAN` существуют в модели данных, но пока не имеют полного интерфейса редактирования.

## Привязка к заливке и обводке

На панели свойств откройте раздел «Заливка» или «Обводка» и выберите цветовую переменную.

- Чтобы создать привязку, выберите переменную. Рядом со свойством появится фиолетовая подпись с её именем.
- Чтобы удалить привязку, используйте отдельное действие в окне выбора. Текущее вычисленное значение сохранится.

Фокус поля и открытие выбора переменной не изменяют привязку. Она может быть удалена только при явном действии или фактическом изменении значения — в зависимости от поведения элемента управления.

После изменения переменной или переключения режима все связанные свойства обновляются автоматически.

## Советы

- Объединяйте связанные токены в коллекции, например `Primitives` для исходных цветов, `Semantic` для смысловых псевдонимов и `Spacing` для интервалов.
- Значения Light и Dark одной темы удобно хранить как режимы одной коллекции.
- Переменные поддерживают псевдонимы: переменная из `Semantic` может ссылаться на значение из `Primitives`.
- Работа с заливками описана в разделе [Фигуры](./drawing-shapes).
