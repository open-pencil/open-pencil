# useI18n

`useI18n()` proporciona la configuración regional activa, la función de traducción y etiquetas para menús, comandos, herramientas, paneles, páginas y diálogos.

Puede usarse para crear un selector de idioma propio sin duplicar los catálogos del SDK.
