# Alternativas a Figma comparadas

Los equipos dejan Figma por motivos distintos: para ser dueños de sus archivos, trabajar sin conexión o en Linux, alojar su propio servidor, elegir su propia IA o dejar de pagar por puesto. Las herramientas de abajo responden a esas necesidades de formas distintas. Esta tabla refleja la documentación de cada producto en noviembre de 2026; sigue los enlaces para ver comparaciones detalladas.

## Para qué sirve cada una

- **OpenPencil** es un editor de diseño que sigue trabajando con archivos de Figma: abre y guarda `.fig`, funciona sin conexión en todas las plataformas de escritorio y está hecho para que lo manejen la IA y los scripts. Cloud es opcional y se puede autoalojar.
- **[Penpot](./penpot)** es la plataforma de diseño de código abierto más consolidada: basada en web, con formato propio, prototipado y un servidor que puedes alojar.
- **[Lunacy](./lunacy)** es un editor de escritorio gratuito y de código cerrado de Icons8 con una gran biblioteca de gráficos integrada.
- **[Grida](https://grida.co)** es un lienzo de código abierto para diseño, imágenes y diapositivas, en una fase temprana de desarrollo.
- **[Graphite](https://graphite.art)** es un editor vectorial y de mapa de bits de código abierto basado en un grafo de nodos, pensado para ilustración y gráficos procedurales más que para diseño de interfaces.
- **[Quant-UX](https://quant-ux.com)** es una herramienta de código abierto para prototipado y pruebas de usabilidad.
- **[Pencil](./pencil)** y **[Paper](./paper)** son herramientas de diseño comerciales hechas para trabajar con agentes de código de IA.
