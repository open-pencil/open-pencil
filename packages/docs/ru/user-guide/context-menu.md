# Контекстное меню

Щёлкните холст правой кнопкой мыши. Если указатель находится над объектом, OpenPencil сначала выделит его. Щелчок правой кнопкой на пустом участке снимает текущее выделение.

## Копировать как

Подменю **Копировать как** предлагает несколько форматов:

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать как текст | — | — |
| Копировать как SVG | — | — |
| Копировать как PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Копировать как JSX | — | — |

- Текст копируется из видимого содержимого выделенных объектов.
- SVG содержит дерево объектов в виде разметки.
- PNG отрисовывается в масштабе 2× и помещается в системный буфер обмена.
- JSX совместим с `renderJsx()` OpenPencil.

## Буфер обмена

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Вырезать | <kbd>⌘</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| Вставить здесь | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd> + <kbd>V</kbd> |
| Дублировать | <kbd>⌘</kbd><kbd>D</kbd> | <kbd>Ctrl</kbd> + <kbd>D</kbd> |
| Удалить | <kbd>⌫</kbd> | <kbd>Backspace</kbd> / <kbd>Delete</kbd> |

Если ничего не выделено, действия над объектами недоступны. Вставка остаётся доступной, когда буфер обмена содержит поддерживаемые данные.

## Порядок наложения

| Действие | Клавиша |
|----------|---------|
| На передний план | <kbd>]</kbd> |
| На задний план | <kbd>[</kbd> |

Команды перемещают объект в начало или конец списка дочерних объектов его родителя.

## Группы и автоматическая компоновка

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Сгруппировать | <kbd>⌘</kbd><kbd>G</kbd> | <kbd>Ctrl</kbd> + <kbd>G</kbd> |
| Разгруппировать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>G</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>G</kbd> |
| Добавить автоматическую компоновку | <kbd>⇧</kbd><kbd>A</kbd> | <kbd>Shift</kbd> + <kbd>A</kbd> |

## Компоненты

Действия с компонентами показаны фиолетовым цветом.

| Действие | macOS | Windows / Linux | Доступно для |
|----------|-------|-----------------|--------------|
| Создать компонент | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>K</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>K</kbd> | Фреймы, группы и несколько объектов |
| Создать набор компонентов | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>K</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>K</kbd> | Не менее двух компонентов |
| Создать экземпляр | — | — | Компоненты |
| Перейти к основному компоненту | — | — | Экземпляры |
| Отсоединить экземпляр | <kbd>⌥</kbd><kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>Alt</kbd> + <kbd>B</kbd> | Экземпляры |

## Видимость и блокировка

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Скрыть / Показать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>H</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>H</kbd> |
| Заблокировать / Разблокировать | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>L</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>L</kbd> |

## Переместить на страницу

Подменю **Переместить на страницу** содержит все страницы, кроме текущей. Выбранная страница становится новым родителем перемещаемых объектов.

## Советы

- На пустом холсте контекстное меню позволяет вставить данные в выбранном месте.
- Команды для компонентов появляются только в подходящем контексте.
- Рядом с командами указаны сочетания клавиш, поэтому меню удобно использовать как справочник.
