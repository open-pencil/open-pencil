- The tab bar follows Figma's desktop app: a home button at its start, as wide as the navigation rail below it, opens the start page, which is no longer a tab, and the tabs list only open designs. The bar is lighter than the panels, and the active tab takes the panel color with a blue file icon. The start page takes the panel color too, so the active home button runs into it without a line between them. The + button and ⌘N or ⌘T create a new design, and closing the last design shows the start page.
- The start page follows Figma's Recents, with the OpenPencil lockup at its top: one list at a time under Recently viewed and Storage tabs, an All files filter for Figma, Pencil, and other files, and the grid and list toggle in one row. The page remembers the list and filter, and Open Storage Workspace… and Settings → Storage open it on Storage. Back to files leaves the main menu, since the home button opens the start page.
