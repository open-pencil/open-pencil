# CanvasSurface

`CanvasSurface` crée l’élément `<canvas>` et relie dimensions, moteur de rendu et saisie.

Dans `CanvasRoot`, le SDK gère les références et l’intégration au moteur ; l’application contrôle disposition et styles.
