# Podręcznik użytkownika

Jak projektować w OpenPencil, w podziale na to, co chcesz zrobić. Jesteś tu pierwszy raz? Zacznij od strony [Rozpoczęcie pracy](/pl/getting-started).

::: tip Skróty klawiszowe
Niektóre strony pokazują skróty dla Twojej klawiatury, którą możesz zmienić na końcu paska bocznego. Pozostałe używają klawiszy Maca: <kbd>⌘</kbd> to <kbd>Ctrl</kbd> w Windows i Linuksie, <kbd>⌥</kbd> to <kbd>Alt</kbd>, a <kbd>⇧</kbd> to <kbd>Shift</kbd>.
:::
