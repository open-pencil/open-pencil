# Библиотеки компонентов

Библиотека делится компонентами, стилями и переменными файла с другими вашими файлами. При каждой публикации она сохраняет новую версию. Файлы, которые используют библиотеку, сами решают, когда её принять.

## Опубликовать библиотеку

1. Откройте файл с компонентами, которыми хотите поделиться.
2. Откройте **Ассеты** и нажмите **Управление библиотеками** рядом с полем поиска.
3. Нажмите **Опубликовать библиотеку**.
4. В первый раз задайте библиотеке идентификатор и название. Идентификатор потом изменить нельзя.
5. Отметьте изменения, которые нужно опубликовать, и при желании добавьте описание.
6. Нажмите **Опубликовать библиотеку**.

Библиотека всегда несёт все стили и коллекции переменных файла. Неотмеченные изменения ждут следующего раза.

## Использовать библиотеку

1. В файле, которому она нужна, откройте **Ассеты → Управление библиотеками**.
2. Включите библиотеку в разделе **Просмотреть библиотеки**.
3. Размещайте её компоненты из раздела **Ассеты** так же, как свои.

Компонент приносит с собой стили и переменные, которые он использует. Здесь их нельзя изменить: измените их в файле библиотеки и опубликуйте снова. Экземпляры остаются редактируемыми, как любые другие.

## Обновиться до новой версии

Откройте **Управление библиотеками → Обновления**, чтобы увидеть, что изменилось. В вашем файле ничего не меняется, пока вы сами не решите.

1. Сравните экземпляр до и после обновления.
2. Обновите выделенный экземпляр, все экземпляры этого компонента, экземпляры на этой странице или все сразу.

Экземпляры сохраняют внесённые в них изменения, в том числе на слоях, которые библиотека переименовала. Теряются только изменения на слоях, которые библиотека удалила. Если варианта экземпляра больше нет в новой версии, при просмотре видно, на какой вариант он переключится. **Отменить** откатывает обновление.

## Где хранятся библиотеки

**Локальные** библиотеки остаются в этом браузере или приложении. Библиотеки из раздела **Хранилище** лежат в [S3-совместимом бакете](./cloud-storage), который вы настроили, поэтому ими могут пользоваться другие люди. Переключайтесь между ними вверху раздела **Просмотреть библиотеки**.

Версии, которые вы уже использовали, хранятся на вашем компьютере, поэтому их компоненты видны и их можно размещать без подключения к сети. При сохранении файл запоминает версии библиотек, которые использует, и открывается так же, даже когда библиотека недоступна.
