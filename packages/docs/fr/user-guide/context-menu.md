# Menu contextuel

Faites un clic droit dans la zone de travail. Si le pointeur se trouve sur un objet, OpenPencil le sélectionne d’abord ; dans une zone vide, la sélection est annulée.

## Presse-papiers

**Copier comme** peut placer la sélection dans le presse-papiers sous forme de :

- texte ;
- SVG ;
- PNG ;
- JSX avec classes Tailwind.

Couper, copier, coller, dupliquer et supprimer sont également disponibles.

## Ordre et organisation

Le menu permet d’amener au premier plan, d’envoyer à l’arrière-plan, d’avancer ou reculer d’un niveau, de grouper, dégrouper et d’ajouter une disposition automatique.

## Composants

Les actions de composant apparaissent en violet : créer un composant, créer une instance, créer un ensemble, détacher une instance et accéder au composant principal.

## Visibilité et verrouillage

**Afficher/Masquer** change la visibilité. **Verrouiller/Déverrouiller** empêche ou autorise les modifications.

## Déplacer vers une page

**Déplacer vers la page** affiche les autres pages du document et y transfère la sélection en conservant sa géométrie.

## Exporter

**Exporter…** ouvre la boîte de dialogue d’exportation pour la sélection actuelle.
