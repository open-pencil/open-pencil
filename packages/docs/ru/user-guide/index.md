# Руководство пользователя

Как работать в OpenPencil, по задачам. Вы здесь впервые? Начните с раздела [Начало работы](/ru/getting-started).

::: tip Сочетания клавиш
На некоторых страницах сочетания клавиш показаны для вашей клавиатуры — её можно сменить в конце боковой панели. На остальных используются клавиши Mac: <kbd>⌘</kbd> — это <kbd>Ctrl</kbd> в Windows и Linux, <kbd>⌥</kbd> — <kbd>Alt</kbd>, а <kbd>⇧</kbd> — <kbd>Shift</kbd>.
:::
