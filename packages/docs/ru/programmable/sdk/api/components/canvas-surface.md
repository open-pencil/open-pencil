# CanvasSurface

`CanvasSurface` отображает элемент `<canvas>`, используемый средствами отрисовки SDK.

Размещайте его внутри `CanvasRoot`: SDK управляет ссылками и подключением отрисовки, а приложение — компоновкой и оформлением.
