# useToolbar

`useToolbar()` gibt den Kontext des nächsten `ToolbarRoot` zurück.

Verwenden Sie das Composable in untergeordneten Komponenten, die Werkzeuge, Aktivzustand oder die Aktion zur Werkzeugauswahl benötigen.
