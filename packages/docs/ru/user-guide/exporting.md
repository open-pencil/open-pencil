# Экспорт и файлы

OpenPencil экспортирует отдельные объекты как изображения, SVG или самостоятельные документы `.fig`. Редактор открывает полные документы `.fig` и `.pen`.

## Экспорт изображений

Выделите объект и откройте раздел «Экспорт» на панели свойств.

### Настройки

- **Масштаб:** от 0,5× до 4×. Для SVG масштаб не показывается, поскольку векторная графика не зависит от разрешения.
- **Формат:** PNG с прозрачным фоном, JPG с белым фоном, WEBP с прозрачным фоном, SVG или отдельный документ `.fig`.

Для одного объекта можно добавить несколько вариантов экспорта. Предварительный просмотр на клетчатом фоне показывает будущий результат.

### Способы экспорта

| Способ | macOS | Windows / Linux |
|--------|-------|-----------------|
| Сочетание клавиш | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>E</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>E</kbd> |
| Контекстное меню | Правая кнопка → Экспорт… | Правая кнопка → Экспорт… |
| Панель свойств | Кнопка «Экспорт» | Кнопка «Экспорт» |

В приложении для компьютера путь выбирается в системном диалоге. В браузере файл загружается обычным способом.

## Копировать как

Контекстное меню позволяет поместить выделение в буфер обмена в нескольких форматах:

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Копировать как текст | — | — |
| Копировать как SVG | — | — |
| Копировать как PNG | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>C</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Копировать как JSX | — | — |

- Текст копируется из видимого содержимого выделенных объектов.
- SVG можно вставить в редактор кода или Inkscape.
- PNG отрисовывается в масштабе 2× и готов для вставки в другие приложения.
- JSX совместим с `renderJsx()` OpenPencil.

## Документы .fig и .pen

OpenPencil использует бинарный формат `.fig` Figma, а также открывает документы `.pen`.

### Открытие

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Открыть файл | <kbd>⌘</kbd><kbd>O</kbd> | <kbd>Ctrl</kbd> + <kbd>O</kbd> |

Диалог выбора показывает файлы `.fig` и `.pen`.

### Сохранение

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Сохранить | <kbd>⌘</kbd><kbd>S</kbd> | <kbd>Ctrl</kbd> + <kbd>S</kbd> |
| Сохранить как | <kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd> | <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> |

**Сохранить** перезаписывает текущий файл, если OpenPencil по-прежнему имеет разрешение на запись. **Сохранить как** позволяет выбрать новый путь.

В Chrome и Edge браузер использует File System Access API. В других браузерах, включая Safari, файл загружается через механизм скачивания.

Сохранённый файл сжимается и содержит миниатюру для файлового менеджера.

### Совместимость с Figma

Файлы, экспортированные из OpenPencil, можно открыть в Figma, а документы Figma — в OpenPencil. Формат `.fig` сохраняет типы объектов, свойства, заливки, обводки, эффекты, векторные данные и параметры компоновки.

## Советы

- Для экранов с высокой плотностью пикселей используйте масштаб 2× или 3×.
- JPG всегда получает белый фон. Для прозрачности выберите PNG или WEBP.
- SVG подходит для последующего редактирования в Illustrator, Inkscape или коде.
