# ToolbarRoot

`ToolbarRoot` stellt die verfügbaren Werkzeuge, das aktive Werkzeug und die Aktion zum Wechseln bereit. Die Anwendung rendert eigene Schaltflächen und bestimmt Anordnung und Gestaltung.
