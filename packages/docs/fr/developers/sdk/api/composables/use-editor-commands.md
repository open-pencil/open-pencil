# useEditorCommands

`useEditorCommands()` fournit les commandes disponibles, leurs libellés et raccourcis, leur disponibilité et une fonction d’exécution.

Utilisez ce registre commun afin que barres et menus affichent les mêmes raccourcis et suivent les mêmes règles.
