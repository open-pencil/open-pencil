- Plugin scripts run through `eval`, the CLI, and MCP follow Figma's font rule: an edit that lays text out again (characters, size, font, spacing, case, alignment, auto-resize, and the matching `setRange…` methods) throws `Cannot write to node with unloaded font` until `figma.loadFontAsync` has loaded every font the text uses, a new font has to be loaded before it is set, and `loadFontAsync` rejects a font that cannot load. Text in a missing font can still take a loaded font for all of its characters.
