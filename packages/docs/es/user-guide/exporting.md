# Exportar

Guarda una capa como archivo, o cópiala directamente en otra app. Para seguir trabajando en un diseño más adelante, [guarda el documento](./files).

## Exportar una capa

1. Selecciona una o varias capas. Sin nada seleccionado, exportas la página.
2. En el panel Diseño, haz clic en **+** junto a **Exportar**.
3. Elige un tamaño y un formato.
4. Haz clic en **Exportar**.

<GuideLegend>

<GuideImage name="exporting/panel" alt="Los ajustes de Exportar con cuatro controles numerados" />

1. **Escala de exportación** define el tamaño de la imagen. Elige uno o escribe el tuyo, como `2.5`.
2. **Formato de exportación** define el tipo de archivo.
3. **Exportar** guarda cada fila como un archivo. Si son varios archivos, llegan en un ZIP.
4. **Vista previa** muestra lo que obtendrás.

</GuideLegend>

Para obtener una capa en varios tamaños, vuelve a hacer clic en **+**. Cada fila nueva duplica la escala de la anterior.

## Elegir un formato

| Para | Usa |
| --- | --- |
| Capturas de pantalla e imágenes con transparencia | PNG |
| Fotos, cuando la transparencia no importa | JPG |
| Imágenes más ligeras para la web | WEBP |
| Iconos e ilustraciones que se mantienen nítidos a cualquier tamaño | SVG |
| Imprimir y compartir páginas | PDF |
| Presentaciones | PPTX |
| Diagramas | draw.io |

La escala solo se aplica a PNG, JPG y WEBP.

**Archivo → Exportar selección** también guarda un archivo `.fig` solo con las capas seleccionadas.

## Copiar en otra app

Haz clic derecho en una capa y elige **Copiar/Pegar como**.

<GuideLegend>

<GuideImage name="exporting/copy-as" other="exporting/copy-as-other" alt="El menú Copiar/Pegar como" />

- **Copiar como PNG** sirve para chats y documentos. Pulsa <Keys mac="⇧ ⌘ C" other="Ctrl Shift C" />.
- **Copiar como SVG** sirve para el código y los editores vectoriales.
- **Copiar como JSX** sirve para el código.
- **Copiar como texto** copia el texto de una capa de texto.

</GuideLegend>
