- Storage-backed component libraries now sync local-first: a background engine mirrors published libraries and their revisions into a per-remote IndexedDB mirror, so the library manager, the assets panel, the AI `list_components`/`insert_component` tools, and update review all read locally. The engine diffs the remote key listing per pull — an unchanged remote costs zero GETs — and pulls only the revisions open documents actually need: enabled bindings, latest revisions that moved past a binding, and (on request) instance and publication-baseline revisions for update review and selective publishing.
- The library manager shows per-library syncing/failed rows with a retry action; update review and the publish dialog wait on syncing baseline revisions and retry automatically when they land.
- Enabling a library binds it to the summary row's latest revision without fetching content, so a library still syncing enables instantly and fills in when its revision arrives.
