# Редактирование текста

OpenPencil позволяет создавать текстовые объекты и редактировать форматированный текст непосредственно на холсте.

## Создание текста

Нажмите <kbd>T</kbd>, затем щёлкните по холсту. Появится пустой текстовый объект с мигающим курсором — можно сразу начинать ввод.

## Редактирование на холсте

Дважды щёлкните существующий текстовый объект. Синяя рамка показывает, что включён режим редактирования. Щёлкните за пределами объекта, чтобы применить изменения и выйти.

Текст отображается средствами самого холста; отдельного видимого поля ввода поверх него нет.

## Перемещение курсора

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| На один символ влево или вправо | <kbd>←</kbd> / <kbd>→</kbd> | <kbd>←</kbd> / <kbd>→</kbd> |
| На строку вверх или вниз | <kbd>↑</kbd> / <kbd>↓</kbd> | <kbd>↑</kbd> / <kbd>↓</kbd> |
| На одно слово | <kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌥</kbd><kbd>→</kbd> | <kbd>Ctrl</kbd> + <kbd>←</kbd> / <kbd>Ctrl</kbd> + <kbd>→</kbd> |
| В начало или конец строки | <kbd>⌘</kbd><kbd>←</kbd> / <kbd>⌘</kbd><kbd>→</kbd> | <kbd>Home</kbd> / <kbd>End</kbd> |

Удерживайте <kbd>Shift</kbd> вместе с клавишей движения, чтобы расширить выделение текста.

## Выделение текста

- Щёлкните внутри текста, чтобы установить курсор.
- Щёлкните и перетащите указатель, чтобы выделить диапазон.
- Дважды щёлкните слово, чтобы выделить его.
- Трижды щёлкните текст, чтобы выделить всё содержимое объекта.

## Форматирование

Форматирование применяется к выделенному диапазону. Если диапазон не выделен, кнопка меняет стиль всего текстового объекта.

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Полужирное начертание | <kbd>⌘</kbd><kbd>B</kbd> | <kbd>Ctrl</kbd> + <kbd>B</kbd> |
| Курсив | <kbd>⌘</kbd><kbd>I</kbd> | <kbd>Ctrl</kbd> + <kbd>I</kbd> |
| Подчёркивание | <kbd>⌘</kbd><kbd>U</kbd> | <kbd>Ctrl</kbd> + <kbd>U</kbd> |

Зачёркивание включается кнопкой **S** в разделе «Типографика». Отдельного сочетания нет, поскольку <kbd>⌘</kbd><kbd>S</kbd> используется для сохранения.

Стиль хранится для каждого символа. Если вводить текст между фрагментами с полужирным и обычным начертанием, новые символы наследуют стиль предыдущего фрагмента.

Форматирование также можно изменить кнопками **B / I / U / S** в разделе «Типографика».

## Редактирование

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Удалить предыдущее слово | <kbd>⌥</kbd><kbd>⌫</kbd> | <kbd>Ctrl</kbd> + <kbd>Backspace</kbd> |
| Удалить до начала строки | <kbd>⌘</kbd><kbd>⌫</kbd> | — |
| Вырезать | <kbd>⌘</kbd><kbd>X</kbd> | <kbd>Ctrl</kbd> + <kbd>X</kbd> |
| Копировать | <kbd>⌘</kbd><kbd>C</kbd> | <kbd>Ctrl</kbd> + <kbd>C</kbd> |
| Вставить | <kbd>⌘</kbd><kbd>V</kbd> | <kbd>Ctrl</kbd> + <kbd>V</kbd> |

## Выбор шрифта

Откройте панель выбора шрифта в разделе «Типографика».

- **Поиск** сокращает список по мере ввода.
- **Предварительный просмотр** показывает название каждого шрифта его собственным начертанием.
- **Виртуальная прокрутка** позволяет без задержек работать с большими каталогами.
- При открытии список прокручивается к текущему семейству и выделяет его.

## Начертание шрифта

Доступные начертания зависят от семейства, например Regular, Medium, Bold и Black.

## Источники шрифтов

- **По умолчанию:** Inter загружается автоматически.
- **Настольное приложение:** системные шрифты и включённые каталоги Google Fonts, Fontsource, Bunny Fonts и Fontshare.
- **Браузер:** системные шрифты доступны в Chrome и Edge; сетевые каталоги требуют настольного приложения.
- **Загруженные шрифты:** приложение сохраняет скачанные начертания для повторного использования на этом компьютере.

## Отсутствующие шрифты и замены

Если нужное семейство или начертание загрузить не удалось, OpenPencil показывает предупреждение над редактором и не выдаёт отображение с заменой за точное воспроизведение типографики.

Раскройте предупреждение, чтобы увидеть затронутые начертания и выбранные замены. Кнопка **Выбрать слои** выделяет соответствующие текстовые объекты. После изменения сетевого доступа, разрешения на локальные шрифты или настроек поставщиков нажмите **Повторить загрузку шрифтов**.

Начертание может быть синтезировано из другого загруженного начертания того же семейства. Если отсутствует всё семейство, используется Inter, когда он доступен.

## Советы

- Список шрифтов загружается при запуске, поэтому панель открывается без задержки.
- Поддерживается ввод через IME для китайского, японского и корейского языков.
- Форматирование сохраняется при открытии и записи `.fig`.
- Переопределения текста внутри экземпляров компонентов описаны в разделе [Компоненты](./components).
