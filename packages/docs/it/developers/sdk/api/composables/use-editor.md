# useEditor

`useEditor()` restituisce l’istanza registrata con `provideEditor()`.

Consente di accedere a stato, SceneGraph, selezione, strumenti, cronologia, pagine, componenti e altre azioni del nucleo.

Il composable genera un errore chiaro se usato fuori dall’albero in cui è stato fornito l’editor.
