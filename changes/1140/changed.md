- The welcome opens on each launch until AI is set up or you tick its new "Don't show this again" box. Closing it with Start designing or the close button hides it only until the next launch; before, any close hid it for good. Help → Show Welcome opens it again at any time, and replaces File → Open the Tour, since the tour is one click away from the welcome.
- The menus follow Figma's. In the browser, the OpenPencil logo opens a main menu, in place of the menu bar that overflowed the left panel: Actions… (the command palette, ⌘K), the File, Edit, View, Object, Vector, Text, and Arrange menus, Preferences, Settings…, and Help. The desktop app gets the same menus in its menu bar, with new Vector and Help menus.
  - View keeps only what changes the view. Theme, Language, and snapping move to Preferences, which the desktop app shows in the File menu, and the performance profiler and developer tools move to Help → Developer.
  - Boolean operations are a submenu of Object. Flatten, Outline Stroke, and Outline Text move to the new Vector menu, Wrap in Auto Layout to Object, and Insert Icon… to File.
  - Help holds Show Welcome, Documentation, What's New, Report an Issue, the desktop app download in the browser, and the app's version. On Windows and Linux it also holds Check for Updates…, which only macOS menus had.
