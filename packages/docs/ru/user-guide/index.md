# Руководство пользователя

OpenPencil — локальный графический редактор с открытым исходным кодом, совместимый с Figma и рассчитанный на автоматизацию и работу с ИИ. В этом руководстве описаны основные возможности редактора.

::: tip Сочетания клавиш в разных операционных системах
В руководстве используется обозначение клавиш macOS: <kbd>⌘</kbd> означает <kbd>Command</kbd> и соответствует <kbd>Ctrl</kbd> в Windows и Linux; <kbd>⌥</kbd> означает <kbd>Option</kbd> и соответствует <kbd>Alt</kbd>; <kbd>⇧</kbd> означает <kbd>Shift</kbd>.
:::
