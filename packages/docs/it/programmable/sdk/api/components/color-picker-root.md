# ColorPickerRoot

`ColorPickerRoot` coordina colore HSV, tonalità, trasparenza e input esadecimale. L’applicazione fornisce la presentazione tramite i propri spazi.

Usalo quando serve la logica completa del selettore senza gli stili dell’app OpenPencil.
