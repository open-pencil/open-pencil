<script setup>
import {
  describeBuildFields,
  describePingFields,
  describeReportFields,
  describeUsageEvents
} from '@open-pencil/feedback/contract'

const columns = [
  { key: 'name', label: 'Field', kind: 'code' },
  { key: 'values', label: 'Values', kind: 'description' }
]

function rows(fields, freeForm = 'A version number') {
  return fields.map((field) => ({
    name: field.name,
    description: field.description,
    values: field.values.length > 0 ? field.values.join(', ') : freeForm
  }))
}

const pingRows = rows(describePingFields())
const buildFields = describeBuildFields()
  .map((field) => field.name)
  .join(', ')
const events = describeUsageEvents()
const reportRows = rows(describeReportFields(), 'Free-form')
</script>

# Конфиденциальность

- Ваши дизайны, имена файлов, названия слоёв, текст, промпты и ключи никогда не покидают ваше устройство, если только вы сами не поделитесь ими или не синхронизируете их либо не приложите дизайн к отправляемому отчёту.
- Официальные сборки раз в день отправляют один анонимный пинг без идентификатора. Его можно выключить.
- Подробная статистика использования отправляется, только если вы согласитесь, когда вас спросят, и это можно прекратить в любой момент.

## Зачем мы вообще что-то собираем

OpenPencil делает небольшая команда. Нам нужно знать, какими платформами, форматами файлов и функциями пользуются люди, чтобы решать, что делать дальше. Ещё нам нужно показывать, что OpenPencil используют, — именно это обеспечивает проекту финансирование. Число активных установок и общая картина того, какие функции важны, отвечают на оба вопроса, ничего не сообщая о вас и вашей работе.

## Ежедневный пинг

Раз в день официальная сборка отправляет на `feedback.openpencil.dev` вот что:

```http
POST https://feedback.openpencil.dev/ping

{ "version": "0.17.0", "platform": "macos", "arch": "arm64", "app": "desktop", "browser": "unknown", "usageStats": "denied", "pingDays": "5-8", "enteredStep": false }
```

<SdkDataTable :columns="columns" :rows="pingRows" />

В нём нет идентификатора, поэтому пинги от одной установки нельзя связать между собой. Ответ на вопрос о статистике использования — единственный способ узнать, сколько людей отказываются, ведь после отказа больше ничего не отправляется. Приложение хранит только дату последнего пинга, чтобы пинговать раз в день, и число дней, в которые оно пинговало. Отправляется лишь ступень, в которую попадает это число: 1, 2, 3–4, 5–8 и так далее, каждый раз вдвое больше, — но никогда само число. Каждая установка проходит ступени по порядку, поэтому сервер может отличить возвращающиеся установки от копий одного сохранённого состояния, которые запускают снова и снова и которые повторяют одну и ту же ступень, — не различая при этом сами установки. Сервер прибавляет единицу к счётчику для этого дня и сборки и единицу к счётчику для этого дня, приложения и ступени. Ещё он прибавляет единицу к счётчику для этого дня, приложения и платформы и сети, из которой пришёл пинг: номера сети и имени оператора в том виде, в каком их сообщает Cloudflare, — например, домашнего интернет-провайдера, университета или облачного хостинга. Так можно отличить реальных людей от автоматических установок в дата-центрах, не зная ничего, что идентифицирует устройство. Больше сервер ничего не хранит. Он не записывает адреса и отклоняет пинг, в котором есть любое другое поле.

В ответ на пинг приходит список сообщений, которые может показать приложение, — например, просьба о пожертвовании или предложение попробовать OpenPencil Cloud: их текст, где в приложении они появляются, как часто и в каких сборках. Сборка, которая их показывает, сама на устройстве решает, пора ли показать сообщение, — по тому, как давно она установлена, по её версии, платформе и тому, вошли ли вы в Cloud, — и там же, на устройстве, хранит, что вы сделали с каждым сообщением, например нажали **Не сейчас**. Ничего из этого не возвращается с пингом. Если вы делитесь статистикой использования, она сообщает, когда одно из этих сообщений было показано, отложено или вы перешли по нему, — по имени сообщения и месту, где оно появилось (события перечислены ниже); сервер хранит их только для сообщений, которые он всё ещё раздаёт или которые встроены в приложение, например его просьбы о пожертвовании. Кнопка сообщения открывает его страницу с именем сообщения в адресе, поэтому по счётчикам посещений сайта видно, какое сообщение привело человека, — без каких-либо сведений о вас или вашем устройстве. Сообщение с сервера — это текст: оно не может выполнять код, показывать изображения или вести куда-либо, кроме openpencil.dev. Встроенная просьба о пожертвовании ведёт на страницу пожертвований, которую указывает проект. Сборки, которые вы компилируете сами, не получают сообщений с сервера.

Пинг включён по умолчанию. Выключите его в **Настройки → Конфиденциальность**; тогда приложение не будет показывать сообщения с сервера.

## Статистика использования

Статистика использования выключена, пока вы не согласитесь. OpenPencil спрашивает один раз — в небольшом окне, которое появляется после экрана приветствия при первом запуске или при одном из следующих запусков, если вы ещё не ответили, — с двумя равноправными вариантами: **Нет, спасибо** и **Делиться статистикой**. Ничего не выбрано за вас, а ответ можно позже изменить в **Настройки → Конфиденциальность**.

Если вы соглашаетесь, приложение создаёт на вашем устройстве случайный идентификатор установки. Он не связан с учётной записью, адресом электронной почты или чем-либо ещё о вас. События использования отправляются с ним вместе с полями сборки, описанными выше (<code>{{ buildFields }}</code>). Когда вы перестаёте делиться статистикой, приложение удаляет идентификатор; при повторном согласии создаётся новый.

Ниже перечислены все события, которые может отправлять приложение. Сервис на `feedback.openpencil.dev` сверяет каждое событие с этим списком и отклоняет любое событие, свойство или значение, которого в нём нет, поэтому и изменённое приложение не сможет отправить через него ничего другого.

<template v-for="event in events" :key="event.name">
  <h3><code>{{ event.name }}</code></h3>
  <p>{{ event.description }}</p>
  <SdkDataTable v-if="event.properties.length" :columns="columns" :rows="rows(event.properties)" />
</template>

Принятые события попадают в [PostHog](https://posthog.com) — сервис продуктовой аналитики — в его облако в ЕС. Запрос отправляет наш сервер, а не ваше устройство, поэтому PostHog никогда не видит ваш адрес. События не создают профилей пользователей и не определяют местоположение. Мы храним статистику использования 12 месяцев.

## Отчёты об ошибках и проблемах

Когда в собственном коде OpenPencil возникает непредвиденная ошибка, официальная сборка добавляет к уведомлению об ошибке кнопку **Сообщить…**; к ошибкам из расширений браузера или без трассировки стека она не добавляется. Если OpenPencil неожиданно закрылся после ошибки или в настольном приложении произошла внутренняя ошибка, при следующем запуске приложение один раз предложит то же самое. Пункт **Справка → Сообщить о проблеме…** доступен всегда. Оба варианта открывают форму, и ничего не отправляется, пока вы не нажмёте **Отправить отчёт**. В разделе **Что будет отправлено** виден точный отчёт до отправки. В нём есть:

- Для ошибки: её тип и сообщение, очищенные от ключей, токенов, адресов электронной почты и вашего имени пользователя в путях к папкам, и место в коде OpenPencil, где она произошла. Ошибки ИИ-провайдеров, которые могут цитировать ваши промпты, отправляются без сообщения.
- То, что вы напишете, и адрес электронной почты, если вы его укажете, чтобы мы могли ответить.
- Поля сборки, описанные выше (<code>{{ buildFields }}</code>), и ваш идентификатор установки, если вы делитесь статистикой использования.
- Если вы оставите включённым **Приложить недавнюю активность**: последние 50 событий из **Настройки → Диагностика**, например ошибки, замеры времени и форматы файлов. В них никогда не входят сообщения чата и результаты инструментов.
- Если вы включите **Приложить этот документ**: открытый дизайн в виде файла `.fig`.

Помимо полей сборки, в отчёте есть такие поля:

<SdkDataTable :columns="columns" :rows="reportRows" />

Отчёты попадают на `feedback.openpencil.dev`, который передаёт их в систему отслеживания ошибок PostHog в его облаке в ЕС — без вашего адреса, профиля пользователя и определения местоположения — и сам ничего из них не хранит. Приложенный дизайн хранится в Cloudflare R2 в ЕС, открыть его может только команда OpenPencil, и через 90 дней он удаляется.

## Как всё это выключить

- В **Настройки → Конфиденциальность** есть переключатель для пинга и отдельный — для статистики использования.
- В настольном приложении оба выключаются, если запустить OpenPencil с `OPENPENCIL_TELEMETRY=0` или `DO_NOT_TRACK=1` в окружении.
- Что-либо отправляют только официальные релизы. Серверы разработки, самостоятельно собранные приложения и форки ничего не отправляют, потому что переключатель, включающий отправку, устанавливается только при сборке релиза.

## Другие сетевые запросы

OpenPencil работает в первую очередь локально, но некоторым функциям нужна сеть. Настольное приложение проверяет обновления при запуске, если вы не выключите это в **Настройки → Основные**. Пункт **Справка → Проверить обновления…** при этом всё равно работает. Всё остальное ниже подключается к сети, только когда вы пользуетесь соответствующей функцией, и только к указанному сервису.

| Функция                                 | Куда подключается                                                                                                                                                                                                                                                                                     |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Проверка обновлений (настольное приложение) | GitHub Releases — за номером последней версии                                                                                                                                                                                                                                                     |
| ИИ-чат и инструменты для изображений    | Провайдер, которого вы настроили, с вашим собственным ключом; список моделей берётся с models.dev. Если провайдер — **OpenPencil Cloud**, то ИИ-сервис, который указывает ваш сервер Cloud, с токеном вашего рабочего пространства                                                                    |
| Комнаты совместной работы               | Напрямую к другим участникам комнаты; публичные брокеры знакомят участников друг с другом, а TURN-ретранслятор передаёт трафик, когда прямое соединение невозможно                                                                                                                                  |
| Облачное хранилище                      | Провайдер хранилища, которого вы настроили                                                                                                                                                                                                                                                            |
| Шрифты                                  | Google Fonts, откуда можно получить используемый в документе шрифт, который не установлен                                                                                                                                                                                                             |
| Иконки                                  | API Iconify — когда вы ищете или вставляете иконки                                                                                                                                                                                                                                                    |
| Иконки в импортированном HTML           | jsDelivr — за индексом иконок, и API Iconify — за иконками-кандидатами, с которыми по имени сравнивается встроенный SVG (сам SVG никогда не отправляется), когда вы импортируете HTML; выключите это в **Настройки → Редактор** или передайте `--no-icon-names` в `openpencil import`                   |
| Открытие по адресу                      | Адрес, который вы открываете, и таблицы стилей, шрифты и изображения, на которые ссылается его страница, — их загружает ваше устройство                                                                                                                                                              |
| Стоковые фото                           | Unsplash или Pexels с вашим собственным ключом — когда вы ищете в них или помещаете одну из их фотографий                                                                                                                                                                                             |

Приложение, сервис обратной связи и эта страница — с открытым исходным кодом. Список событий находится в [`packages/feedback/src/contract`](https://github.com/open-pencil/open-pencil/tree/master/packages/feedback/src/contract), и таблицы выше генерируются из него.
