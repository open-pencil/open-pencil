# ToolbarItem

`ToolbarItem` fornisce lo stato attivo di uno strumento e ne gestisce la selezione.

Dentro `ToolbarRoot`, l’applicazione può rappresentare un pulsante personalizzato e riutilizzare la logica condivisa.
