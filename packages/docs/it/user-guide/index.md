# Guida utente

Come progettare in OpenPencil, con le pagine raggruppate in base a ciò che vuoi fare. Sei nuovo? Inizia da [Per iniziare](/it/getting-started).

::: tip Scorciatoie
Alcune pagine mostrano le scorciatoie per la tua tastiera, che puoi cambiare in fondo alla barra laterale. Le altre usano i tasti del Mac: <kbd>⌘</kbd> corrisponde a <kbd>Ctrl</kbd> su Windows e Linux, <kbd>⌥</kbd> ad <kbd>Alt</kbd> e <kbd>⇧</kbd> a <kbd>Shift</kbd>.
:::
