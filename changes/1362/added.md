- The AI assistant can use models through OpenPencil Cloud: choose **OpenPencil Cloud** as a model's provider in **Settings → AI** and the workspace whose plan pays for it, with the models and prices the server offers. The chat shows how many credits the workspace has left; when they run out, it offers **Manage plan** where the server bills, and on a self-hosted server says when the allowance renews.
- Self-hosted OpenPencil Cloud servers can offer AI through the AI relay, `dist-standalone/ai-relay.mjs`, which forwards requests to one OpenAI-compatible provider with your key and holds each workspace to its monthly credit allowance.
