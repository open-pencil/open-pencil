# Совместимость с Figma

Сравнение возможностей Figma Design с текущим состоянием OpenPencil.

::: tip Статус
✅ Поддерживается полностью · 🟡 Поддерживается частично · 🔲 Пока не реализовано
:::

**Покрытие:** учтены 128 из 156 возможностей Figma — 112 ✅ полностью, 16 🟡 частично и 28 🔲 пока отсутствуют. Обновлено 27 октября 2026 года.

## Интерфейс и навигация

| Возможность | Статус | Примечания |
|-------------|--------|------------|
| Панель инструментов | ✅ | Нижняя панель в стиле UI3: перемещение, фрейм и секция, фигуры, перо и карандаш, текст, рука и комментарии; набор инструментов настраивается, есть выбор иконок |
| Панель слоёв | ✅ | Дерево с раскрытием, перетаскиванием, видимостью и изменяемой шириной |
| Страницы | ✅ | Добавление, удаление и переименование; отдельное состояние области просмотра |
| Панель свойств | ✅ | Внешний вид, заливка, обводка, эффекты, типографика, компоновка, сетки компоновки, ограничения, положение, маска, свойства компонентов, цвета выделения и экспорт; ширина меняется |
| Масштаб и перемещение | ✅ | <kbd>Ctrl</kbd> + прокрутка, жест сведения пальцев, <kbd>⌘</kbd><kbd>+</kbd>/<kbd>−</kbd>, <kbd>⌘</kbd><kbd>0</kbd>, <kbd>⌘</kbd><kbd>1</kbd>, <kbd>⌘</kbd><kbd>2</kbd>, <kbd>Space</kbd> + перетаскивание, средняя кнопка и инструмент «Рука» |
| Линейки | ✅ | Верхняя и левая линейки с диапазоном выделения и координатами |
| Фон холста | ✅ | Отдельный цвет для каждой страницы |
| Направляющие | ✅ | Перетаскиваются с линеек на холст или во фреймы; выделение, перемещение, дублирование, удаление и отмена; сохраняются в `.fig` |
| Палитра команд | ✅ | <kbd>⌘</kbd><kbd>K</kbd> открывает поиск по действиям редактора и приложения |
| Контекстное меню | ✅ | Буфер обмена, порядок, группы, компоненты, видимость, блокировка и перенос на страницу |
| Сочетания клавиш | 🟡 | Инструменты, редактирование, логические операции, Flatten, маски, компоненты, выравнивание, порядок, навигация и форматирование текста; нет Scale (<kbd>K</kbd>), Arrow, пипетки (<kbd>I</kbd>) и инструмента масштаба |
| Поиск и замена | 🔲 | Нет поиска и замены текста во всём документе |
| Контуры слоёв | 🔲 | Нет каркасного представления всех слоёв |
| Собственная миниатюра | 🔲 | Как и в Figma без страницы Cover, миниатюрой сохранённого файла служит первая страница; выбрать свою нельзя |
| Настройка шага перемещения | 🔲 | Используются 1 и 10 пикселей; собственные значения не задаются |
| Меню приложения | ✅ | File, Edit, View, Object, Text и Arrange в браузере; системные меню в Tauri |
| Инструменты ИИ | 🟡 | 126 инструментов в чате с ИИ, у агентов для программирования (ACP) и в MCP; стоковые фото и векторизация изображений; нет генерации изображений и поиска с ИИ |
