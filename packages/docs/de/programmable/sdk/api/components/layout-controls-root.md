# LayoutControlsRoot

`LayoutControlsRoot` gibt die API von `useLayout()` über seinen Slot weiter.

Die Anwendung kann ein eigenes Panel für Anordnung und Größe darstellen und dabei Zustand und Aktionen des SDK verwenden.
