# Collab

How a room's Yjs document maps to and from a SceneGraph, and how a room keeps that document in step with an editor over a transport. Hosts add who a peer is, presence, and calls: the app's live in `src/app/collab` (`src/AGENTS.md`), the Cloud relay transport in `@open-pencil/cloud/client`. A server reads a room the same way the editor does.

- The package depends on `@open-pencil/scene-graph`, `@open-pencil/std`, Yjs and its protocols, and small libraries, never Vue or app code, and reaches an editor only through the `CollabEditor` interface, or `RoomEditor` for a whole room; a graph with no events and nothing to redraw is a complete editor (`packages/collab/tests/graph-sync.test.ts`).
- The room's messages, `COLLAB_ACTIONS` and the sync encoding, are this package's (`src/room/protocol.ts`); the Cloud relay reads the document ones to persist rooms and drop viewer writes, so a new document channel changes both (`packages/cloud/tests/server/collaboration/relay/hub.test.ts`).
- `openCollabRoom` owns the room's document, its bindings, and leaving; it keeps no timers and reads no storage, which hosts pass in, such as the app's IndexedDB copy through `openSavedCopy` (`src/app/collab/session.ts`, `tests/app/collab/session.test.ts`).
- A shared document records each layer's parent history, order key and page, never `parentId` or `childIds`, and only Share or a room's conversion sets its root in `meta`; local edits are written by `writeLocalPlacement` and remote changes applied by `applySharedTree` in `packages/collab/src/shared-tree/sync.ts`, which resolve the tree with `LayerTree` from `packages/collab/src/tree/` (`tests/app/collab/random-edits.test.ts`).
- What a document holds outside its layers, its document node's plugin data, comment threads, libraries and color space, travels in the room's own maps through `bindDocumentSync` (`packages/collab/src/document/sync.ts`), entry by entry and thread by thread, never on the root layer, so people changing it at once all keep their change (`tests/app/collab/document/sync.test.ts`).
- Changing how a shared document records data bumps `TREE_FORMAT` and `COLLAB_APP_ID` together, so mismatched builds never meet; rooms saved by an earlier format are not converted (`packages/collab/src/shared-tree/fields.ts`).
