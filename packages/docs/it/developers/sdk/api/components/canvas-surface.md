# CanvasSurface

`CanvasSurface` crea l’elemento `<canvas>` e collega dimensioni, motore di rendering e input.

Dentro `CanvasRoot`, l’SDK gestisce riferimenti e integrazione; l’applicazione controlla disposizione e stili.
