# FontPickerRoot

`FontPickerRoot` proporciona un selector de fuentes con lista asíncrona de familias y búsqueda. Usa Reka UI Combobox, pero permite sustituir el botón, el campo de búsqueda, los elementos, el indicador de selección y el estado vacío mediante ranuras.

Las propiedades y eventos generados se documentan en la tabla de API de esta página.
