# Figma Alternatives Compared

Teams leave Figma for different reasons: to own their files, to work offline or on Linux, to host their own server, to choose their own AI, or to stop paying per seat. The tools below answer those needs differently. This table reflects each product's own documentation in November 2026; follow the links for detailed comparisons.

| --------------------------------- | --------------- | ---------------------------------- | -------------------------------------- | ----------------- | ------------ | ------------------------------------- |
| **OpenPencil**                    | MIT, Apache 2.0 | macOS, Windows, Linux, web         | Opens and saves `.fig`                 | Yes               | Yes          | Built-in assistant, MCP server, CLI   |

## What Each Is For

- **OpenPencil** is a design editor that keeps working with Figma files: it opens and saves `.fig`, runs offline on every desktop platform, and is built to be driven by AI and scripts. Cloud is optional and self-hostable.
- **[Penpot](./penpot)** is the most established open-source design platform, web-based with its own format, prototyping, and a server you can host.
- **[Lunacy](./lunacy)** is a free, closed-source desktop editor from Icons8 with a large built-in graphics library.
- **[Grida](https://grida.co)** is an open-source canvas for design, images, and slides, early in development.
- **[Graphite](https://graphite.art)** is an open-source vector and raster editor built on a node graph, for illustration and procedural graphics rather than interface design.
- **[Quant-UX](https://quant-ux.com)** is an open-source prototyping and usability-testing tool.
- **[Pencil](./pencil)** and **[Paper](./paper)** are commercial design tools made for working with AI coding agents.
