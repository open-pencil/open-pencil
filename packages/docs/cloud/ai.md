# AI on Cloud

When your workspace's plan includes AI and the server offers it, the AI assistant can use models through Cloud instead of a key of your own. In **Settings → Models**, add a model, choose **OpenPencil Cloud** as the provider, and pick the workspace whose plan pays for it; the models and their prices come from the server. **OpenPencil Cloud** is listed while you are signed in to the server Home shows.

Each request uses the credits of the workspace owner's plan for the month, which every workspace they own shares, so requests in one can use up the credits of the others. While the chat's Design model runs on Cloud, a banner over the editor warns when they run low and again when they run out. If the server bills and says who owns the workspace, it offers **Buy credits** to the owner and asks anyone else to go to the owner; the assistant also offers **Manage plan** once they are out. Self-hosted servers run their own AI service with their own models and limits ([self-hosting guide](./self-hosting/ai-services)).
