# Облачное хранилище

OpenPencil может хранить документы в вашем собственном бакете в любом S3-совместимом сервисе: AWS S3, Backblaze B2, Cloudflare R2, MinIO и других. Никакого сервера OpenPencil посередине нет: редактор обращается к вашему бакету напрямую с вашими собственными ключами доступа.

## Подключить бакет

Откройте **Настройки → Хранилище**, выберите **Хранилище S3** и заполните поля:

| Поле                  | Что ввести                                                                     |
| --------------------- | --------------------------------------------------------------------------------- |
| **Конечная точка**    | URL S3 API провайдера, включая нужный путь. См. примеры ниже.  |
| **Бакет**             | Имя бакета.                                                                  |
| **Регион**            | Необязательно. Если оставить пустым, регион берётся из конечной точки, а если это невозможно — `us-east-1`. |
| **Идентификатор ключа доступа** | Ключ доступа с правами на чтение, запись, просмотр списка и удаление в бакете.            |
| **Секретный ключ доступа** | Секрет этого ключа.                                                                 |

Примеры конечных точек:

- AWS S3: `https://s3.eu-west-1.amazonaws.com`
- Backblaze B2: `https://s3.eu-central-003.backblazeb2.com`
- Cloudflare R2: `https://<account-id>.r2.cloudflarestorage.com`
- MinIO: `http://localhost:9000` или адрес, на котором слушает ваш сервер

Нажмите **Проверить подключение**, чтобы проверить конечную точку, ключи и бакет перед сохранением, а затем **Сохранить**. OpenPencil сам добавляет бакет к конечной точке — как `{endpoint}/{bucket}/{key}`, — поэтому не указывайте имя бакета в конечной точке.

В настольном приложении ключи доступа хранятся в системном хранилище учётных данных. В браузере они шифруются в хранилище браузера или хранятся только до закрытия сеанса, если выключен параметр **Настройки → Основные → Запоминать API-ключи на этом устройстве**.

## Разрешить веб-приложение в CORS

Браузер может обращаться только к бакету, который разрешает запросы с источника страницы, поэтому веб-приложению нужно правило CORS в бакете. Настольное приложение отправляет запросы напрямую, и ему правило не нужно.

Добавьте правило вроде этого, указав источники, с которых вы открываете OpenPencil:

```json
[
  {
    "AllowedHeaders": ["*"],
    "AllowedMethods": ["GET", "PUT", "POST", "DELETE", "HEAD"],
    "AllowedOrigins": ["https://cloud.openpencil.dev"],
    "ExposeHeaders": ["ETag", "Content-Range", "x-amz-request-id", "x-amz-id-2", "x-amz-version-id"],
    "MaxAgeSeconds": 3600
  }
]
```

Веб-приложение переезжает с app.openpencil.dev на cloud.openpencil.dev: в правило, настроенное для старого адреса, нужно добавить новый. Задайте правило в консоли AWS в разделе бакета **Permissions → Cross-origin resource sharing**, в панели Cloudflare в разделе бакета R2 **Settings → CORS policy** или с помощью CLI вашего провайдера. Если правила нет, **Проверить подключение** сообщит, что браузер не смог обратиться к бакету с текущего сайта.

## Сохранить документ в хранилище

Откройте или создайте документ, затем выберите **Файл → Сохранить в…**. Если выбирать пространство Cloud не из чего, документ сохраняется прямо в бакет; иначе выберите бакет в списке. Вкладка остаётся привязанной к нему: **Сохранить** и автосохранение теперь записывают в хранилище, а не в локальный файл. Локальный `.fig`, который был открыт, сохраняет своё последнее сохранённое содержимое.

Чтобы открыть сохранённые документы, выберите свой бакет на боковой панели главной. **Новый дизайн** при выбранном бакете создаёт документ в нём. Главная показывает все документы в бакете с превью, прочитанным из самого документа, поэтому для показа большого файла в списке скачивается только встроенная в него миниатюра.

## Как работает сохранение

При сохранении документ сначала записывается на этом устройстве и загружается в фоне, поэтому редактирование никогда не ждёт сети. Если загрузка не удалась или вы не в сети, она повторяется с растущими паузами, а незавершённая работа возобновляется, когда вы снова подключитесь или измените настройки хранилища.

Каждый документ загружается целиком. Если два устройства сохраняют один и тот же документ, побеждает последняя загрузка.

Открытые вами документы остаются в кеше на устройстве, чтобы быстрее открываться снова, — до 500 МБ. Когда кеш заполнен, удаляются только полностью загруженные копии, и в следующий раз при открытии они скачиваются заново.

## Библиотеки компонентов

В бакете можно хранить и библиотеки компонентов. В **Ассеты → Управление библиотеками** переключите источник на **Хранилище**, чтобы публиковать и подключать библиотеки там, а не на этом устройстве. Публикация использует условную запись, поэтому два человека, одновременно публикующие одну и ту же библиотеку, не перезапишут ревизии друг друга. О публикации и обновлении библиотек читайте в разделе [Библиотеки компонентов](./component-libraries).

## Что лежит в бакете

OpenPencil записывает только под двумя префиксами и не трогает ничего другого в бакете:

- `open_pencil_storage/canvases/` — каждый документ как `<id>.fig`, а его имя и время изменения — в `<id>.meta.json`.
- `open-pencil/libraries/` — `manifest.json` каждой библиотеки и её опубликованные ревизии.

## Заметки о провайдерах

- **Cloudflare R2** требует в правиле CORS точный источник веб-приложения; источники с подстановочными знаками, например `https://*.example.com`, он не принимает.
- **MinIO** отвечает на запросы CORS с любого источника, если не настроить иначе.
- **`rclone serve s3`** работает с двумя ограничениями. Он отклоняет предварительные запросы CORS, поэтому веб-приложению нужен перед ним обратный прокси, который на них отвечает; настольному приложению — нет. Он также игнорирует условную запись, поэтому одновременные публикации библиотеки не обнаруживаются.
