# useFontPicker

`useFontPicker(options)` управляет доступными семействами шрифтов, поисковым запросом, состоянием открытия и выбранным семейством.

Используйте эту компонуемую функцию, если возможностей `FontPickerRoot` недостаточно и нужен собственный интерфейс выбора шрифта.
