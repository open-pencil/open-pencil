# Агенты для программирования

Настольное приложение может использовать как свой ИИ агента для программирования, который у вас уже есть: Claude Code, Codex, [Antigravity CLI](#antigravity), Gemini CLI, [Cursor](#cursor), [Grok Build](#grok-build) или [Pi](#pi). Агент работает на вашем компьютере по вашей собственной подписке, а OpenPencil даёт ему инструменты для работы с холстом.

Агентам для программирования нужно [настольное приложение](/ru/download): браузер не может запускать программы на вашем компьютере.

## Настроить агента

1. Установите коннектор агента, как показано в его разделе ниже. Claude Code и Codex не нужны другие программы.
2. Установите MCP-сервер OpenPencil, который даёт агенту инструменты для холста:

   ```sh
   npm install -g @open-pencil/mcp
   ```

3. Откройте **Настройки → Модели → Пройти пошаговую настройку** и выберите агента в разделе **Агенты для программирования на этом компьютере**.
4. Убедитесь, что агент и MCP-сервер показаны как установленные. **Установить адаптер** установит коннектор за вас.
5. Если агент не вошёл в аккаунт, нажмите **Войти**. Пошаговая настройка показывает аккаунт, которым пользуется агент, например его тариф и почту.

**Инструменты OpenPencil** показывает, доступны ли агенту инструменты для холста. **Проверить снова** проверяет ещё раз после того, как вы что-то установили или вошли в аккаунт.

Если вы уже пользуетесь агентом в терминале, он может настроить себя сам: нажмите **Скопировать промпт настройки** на его карточке и вставьте промпт в агента.

## Выбрать модель и режим

Агент — такая же модель, как любая другая в **Настройки → Модели**, поэтому он может быть **Дизайн-агентом**, выполнять **Быстрые задачи**, писать **Проверки** или, если читает изображения, быть моделью для роли **Зрение**. В роли **Быстрые задачи** агент даёт названия разговорам, но сводки всё равно пишет дизайн-агент, а Pi не делает ни того, ни другого. Одного и того же агента можно добавить дважды с разными настройками.

В настройках агента:

- **Модель**: **Модель агента по умолчанию** оставляет выбор агенту; можно также выбрать одну из предлагаемых им моделей. Если список не загружается, выберите **Пользовательская модель…** и введите ID модели.
- **Уровень рассуждений**: собственные уровни агента для выбранной модели, например Max у Claude Code или Ultra у Codex.
- **Режим**: что агенту можно делать, не спрашивая вас, в терминах самого агента, например Manual, Accept edits, Plan, Auto и Bypass permissions у Claude Code или от Read-only до Full access у Codex.
- **Ввод изображений**: выключите, если выбранная модель не читает изображения.

Меню рядом с кнопкой отправки меняет модель, уровень рассуждений и режим для текущего чата, начиная со следующего сообщения.

## Claude Code

```sh
npm install -g @agentclientprotocol/claude-agent-acp
```

Войдите из пошаговой настройки или запустите `claude` и введите `/login`. Если браузер не может передать вход обратно, страница входа покажет код, который нужно вставить в пошаговую настройку.

## Codex

```sh
npm install -g @agentclientprotocol/codex-acp
```

Войдите через ChatGPT из пошаговой настройки или запустите `codex login`.

Старый коннектор, `@zed-industries/codex-acp`, устанавливает программу с тем же именем, но не умеет входить в аккаунт. Пошаговая настройка попросит его удалить.

## Antigravity CLI {#antigravity}

Antigravity CLI — агент Google для Gemini. Коннектор ему не нужен. Установите его с [сайта Antigravity](https://antigravity.google):

```sh
curl -fsSL https://antigravity.google/cli/install.sh | bash
```

В Windows вместо этого выполните в PowerShell:

```powershell
irm https://antigravity.google/cli/install.ps1 | iex
```

Запустите `agy` один раз и выберите способ входа. Пошаговая настройка показывает его как установленный, но не может показать его аккаунт.

Перед началом работы агент иногда просит показать содержимое своей папки `~/.gemini/antigravity-cli/mcp`. Разрешите: при отказе он завершает свой ход.

## Gemini CLI

```sh
npm install -g @google/gemini-cli
```

Коннектор ему не нужен. Запустите `gemini` один раз и выберите способ входа. С личными аккаунтами Google войти в Gemini CLI больше нельзя: для них используйте [Antigravity CLI](#antigravity).

## Cursor

CLI Cursor не нужен коннектор. Установите его по [руководству по установке CLI](https://cursor.com/docs/cli/installation):

```sh
curl https://cursor.com/install -fsS | bash
```

В Windows используйте команду PowerShell с той же страницы. Чтобы войти, один раз выполните `cursor-agent login`. У моделей Cursor уровень рассуждений указан в названии.

## Grok Build

Grok Build не нужен коннектор. Установите его по [руководству Grok Build](https://docs.x.ai/build/overview):

```sh
curl -fsSL https://x.ai/cli/install.sh | bash
```

В Windows используйте команду PowerShell с той же страницы. Чтобы войти, один раз выполните `grok login`.

## Pi

Pi работает через программу-компаньон OpenPencil, которой нужен Node.js 22.15 или новее либо Bun. Пошаговая настройка устанавливает её в один щелчок, или установите её сами:

```sh
npm install -g @open-pencil/harness
```

Pi использует провайдеров, в которые вы вошли в Pi, поэтому вставлять ключ не нужно. Запустите `pi`, войдите командой `/login` и выберите модель по умолчанию командой `/model`. Чтобы использовать в OpenPencil другую модель, введите её как `provider/model` в настройках Pi в OpenPencil. С ключом [AI Gateway](https://vercel.com/ai-gateway) Pi использует вместо этого шлюз.

Pi не читает изображения. После перезапуска Pi или OpenPencil разговор продолжается в новом сеансе Pi.

## Устранение неполадок

- **Не находится после установки.** Приложения, запущенные из Dock или меню «Пуск», видят не все папки, которые видит терминал. OpenPencil ищет в обычных папках npm, Bun, Volta, mise и Homebrew. Если ваша папка в другом месте, добавьте её в `PATH` своей оболочки входа и перезапустите OpenPencil.
- **Нужно обновление.** Версия MCP-сервера или компаньона Pi не совпадает с версией приложения. Нажмите кнопку обновления или выполните команду, которую показывает пошаговая настройка, а затем **Проверить снова**.
- **Агенту недоступны инструменты OpenPencil** или он не может редактировать холст. Убедитесь, что MCP-сервер показан как установленный в пошаговой настройке и запущен в **Настройки → MCP**. Codex пропускает сервер OpenPencil, если в его собственном `config.toml` есть сервер с именем `open-pencil`: удалите эту запись.
- **Агент просит войти в аккаунт.** Нажмите **Войти** в пошаговой настройке или войдите собственной командой агента, а затем отправьте сообщение ещё раз.

Агент работает в собственной папке в данных приложения OpenPencil, поэтому не подхватывает настройки проектов из вашей домашней папки. Он по-прежнему использует свои настройки, например MCP-серверы и правила в `~/.codex` или `~/.claude`.
