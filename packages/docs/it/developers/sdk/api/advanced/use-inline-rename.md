# useInlineRename

`useInlineRename(onCommit)` gestisce stato di modifica, focus, clic esterno, Invio ed Esc.

Usa il composable in elenchi di pagine, alberi dei livelli e altre interfacce in cui il nome cambia senza una finestra separata.
