# Редактирование векторов

В режиме редактирования векторов изменяется геометрия самого контура: положение опорных точек, форма сегментов и рычаги Безье. Обычные преобразования всего объекта в этом режиме недоступны.

## Вход в режим

1. Выберите векторный объект инструментом «Выделение».
2. Дважды щёлкните его контур.

## Выход

Нажмите <kbd>Escape</kbd> или перейдите в другой режим редактирования.

## Отличия режима

- Обычная рамка преобразования объекта отключается.
- Можно изменять опорные точки, сегменты и рычаги.
- При наведении на углы рамки не включаются изменение размера и поворот.

## Основные действия

### Перемещение опорной точки

Перетащите опорную точку. Связанные сегменты и форма контура обновляются во время движения.

### Изменение рычага Безье

Перетащите рычаг выбранной опорной точки. Поведение второго рычага зависит от текущего типа точки.

## Модификаторы при перетаскивании рычага

| Режим | macOS | Windows / Linux |
|-------|-------|-----------------|
| Непрерывный | <kbd>Cmd</kbd> + перетаскивание | <kbd>Ctrl</kbd> + перетаскивание |
| Угловой | <kbd>Option</kbd> + перетаскивание | <kbd>Alt</kbd> + перетаскивание |
| Зафиксировать направление | <kbd>Shift</kbd> + перетаскивание | <kbd>Shift</kbd> + перетаскивание |

### Непрерывный режим

- Активный рычаг остаётся на одной прямой со вторым.
- Изменяется только длина активного рычага.
- Режим подходит для плавного перехода без угла.

### Угловой режим

- Активный рычаг изменяется независимо.
- Второй рычаг остаётся на месте.
- Режим создаёт резкий переход в опорной точке.

### Фиксация направления

Для точек типа **Continuous** или **Symmetric** направление рычагов фиксируется в положении до начала перетаскивания. Движение меняет только длину одного или обоих рычагов в зависимости от типа точки.

## Изменение изгиба перетаскиванием точки

Если перетаскивать опорную точку с нажатой <kbd>Cmd</kbd> или <kbd>Ctrl</kbd>, OpenPencil выбирает нужный рычаг по направлению входящего сегмента, а не по расстоянию до ближайшей соседней точки.

Это работает и для точек с несколькими ответвлениями в векторной сети. После выбора целевой рычаг не меняется до конца текущего перетаскивания.

## Инструмент «Перо» в режиме редактирования

Если активно «Перо»:

- щёлкните сегмент, чтобы вставить новую опорную точку и разделить сегмент;
- щёлкните конечную точку открытого контура, чтобы продолжить рисование;
- удерживайте <kbd>Option</kbd> или <kbd>Alt</kbd> и щёлкните опорную точку, чтобы удалить её, если топология это допускает.

Создание и замыкание контуров описано в разделе [Инструмент «Перо»](./pen-tool.md).

## Пример работы

1. Создайте фигуру инструментом «Перо».
2. Дважды щёлкните контур, чтобы перейти к редактированию.
3. Переместите опорные точки и уточните силуэт.
4. Измените рычаги:
   - с <kbd>Cmd</kbd> или <kbd>Ctrl</kbd> для плавного перехода;
   - с <kbd>Option</kbd> или <kbd>Alt</kbd> для независимого изменения;
   - с <kbd>Shift</kbd> только для изменения длины.
5. Нажмите <kbd>Escape</kbd>.
