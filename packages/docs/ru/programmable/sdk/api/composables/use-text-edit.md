# useTextEdit

`useTextEdit()` связывает DOM-ввод текста с моделью редактирования текста на холсте редактора.

Координирует:

- ввод текста через `textarea`;
- ввод с помощью IME;
- мигание caret;
- обработку Delete и Backspace;
- команды начертания: полужирный, курсив и подчёркивание;
- перенос изменений текста обратно в scene graph.

## Использование

```ts
useTextEdit(canvasRef, editor)
```

## Базовый пример

Используйте в компоненте-владельце холста вместе с `useCanvas()` и `useCanvasInput()`.

## Практические примеры

### Сочетания клавиш для начертания

Пока пользователь редактирует текст, `useTextEdit()` обрабатывает сочетания клавиш для полужирного, курсивного и подчёркнутого начертания.

### Синхронизация текста

По мере ввода функция обновляет текст и style runs в scene graph.

## Примечания

Это composable для интеграции текстового редактора с холстом. Он не предназначен для обычных текстовых полей.
