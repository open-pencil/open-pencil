# Переход с pen.dev

OpenPencil открывает файлы `.pen` из pen.dev, который раньше назывался Pencil. Дизайн открывается в виде слоёв, которые можно редактировать, а вы продолжаете работать с тем ИИ-агентом, к которому привыкли.

## Открыть файл `.pen`

Нажмите <Keys mac="⌘ O" other="Ctrl O" /> и выберите файл или перетащите его в окно. Если у вас установлено настольное приложение, файл можно открыть и прямо из Finder или Проводника.

OpenPencil читает файлы `.pen`, но не записывает их. При первом сохранении он спросит, куда положить новый файл `.fig` с тем же именем, что у исходного; браузер без диалога сохранения вместо этого скачает его. Файл `.pen` остаётся без изменений, а файл `.fig` открывается и в Figma.

## Что переносится

- Фреймы, фигуры и контуры с заливками, обводками и эффектами.
- Текст и раскладка: строки, столбцы, интервалы и отступы.
- Компоненты и их экземпляры вместе с изменениями, внесёнными в каждый экземпляр.
- Темы — в виде коллекций [переменных](./variables). Параметры тем, которые сочетаются в ваших переменных, например цветовой режим и плотность, попадают в одну коллекцию, режимы которой — их сочетания; отдельный параметр получает собственную коллекцию.
- Иконки и изображения.

Кое-что пока не переносится:

- Слои из других файлов, которые импортирует документ.
- Слои скриптов, браузера, шейдеров, заметок и контекста.
- В браузере — изображения, сохранённые рядом с файлом. Чтобы они сохранились, откройте файл в настольном приложении.

## Продолжить работу с ИИ-агентом

Агент, с которым вы работаете в pen.dev, может работать и в OpenPencil:

- В настольном приложении используйте в качестве ИИ-чата [Claude Code, Codex, Cursor или другой агент для программирования](./coding-agents), который у вас уже есть.
- Или подключите агента к [MCP-серверу](/developers/mcp-server) OpenPencil из его собственного терминала или редактора — и он будет редактировать открытый документ.

Агенты редактируют документ, пока он открыт, поэтому файл `.pen` на диске им не нужен.
