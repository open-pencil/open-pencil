# CanvasRoot

`CanvasRoot` proporciona el contexto a sus componentes descendientes. El SDK gestiona la integración con el editor; la aplicación decide disposición y estilos.

Use [CanvasSurface](./canvas-surface) dentro de este componente o acceda al contexto con [useCanvasContext](../advanced/use-canvas-context).
