- Easing and timing variables, as in Figma: open, edit and save them in `.fig` files and through the Figma plugin API, edit timings in milliseconds and easings in an editor with Figma's curve and spring presets, draggable handles and spring physics. Timings export as CSS times and design token `duration`; curves as CSS timing functions, Tailwind `--ease-*` tokens and design token `cubicBezier`. Springs have no CSS or design token form and are left out of both, and holds out of design tokens (#2326).
