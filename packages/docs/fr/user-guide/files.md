# Ouvrir et enregistrer

OpenPencil ouvre et enregistre les fichiers `.fig`, le format qu’utilise Figma. Il ouvre aussi les pages web et les fichiers `.pen` de pen.dev.

## Ouvrir un document

Appuyez sur <Keys mac="⌘ O" other="Ctrl O" /> et choisissez un fichier, ou faites-en glisser un sur la fenêtre. Il s’ouvre dans un nouvel onglet.

## Ouvrir une page web

<GuideLegend>

<GuideImage name="files/open-url" alt="La boîte de dialogue Ouvrir depuis une URL avec une adresse et trois tailles de fenêtre" />

1. Choisissez **Fichier → Ouvrir depuis une URL**.
2. Saisissez l’adresse.
3. Choisissez la taille de fenêtre pour laquelle la page est mise en page.
4. Cliquez sur **Ouvrir**.

</GuideLegend>

La page devient des calques que vous pouvez modifier. Une adresse peut aussi mener à une image ou à un fichier de design.

L’application de bureau ouvre n’importe quelle adresse et exécute d’abord les scripts de la page. Si cela bloque sur une bannière de cookies ou une page de connexion, désactivez **Exécuter les scripts de la page**. Dans le navigateur, seuls les sites qui l’autorisent peuvent être ouverts, et leurs scripts ne sont pas exécutés.

Pour arrêter, fermez l’onglet.

## Ajouter un fichier à votre design

Choisissez **Fichier → Placer**, ou faites glisser le fichier sur le canevas. Vous pouvez placer des images, des fichiers SVG et des pages HTML.

## Enregistrer

- **Enregistrer** avec <Keys mac="⌘ S" other="Ctrl S" /> met à jour le fichier que vous avez ouvert. Les navigateurs qui ne peuvent pas écrire dans vos fichiers, comme Firefox et Safari, le téléchargent à la place.
- **Enregistrer sous** avec <Keys mac="⇧ ⌘ S" other="Ctrl Shift S" /> vous permet de choisir un nouveau nom ou un nouvel emplacement.

Les fichiers dans d’autres formats, comme `.pen`, sont enregistrés dans un nouveau fichier `.fig`, et l’original reste tel quel. Les fichiers enregistrés s’ouvrent dans Figma.

## Réduire la taille d’un fichier

1. Cliquez sur une partie vide du canevas pour que rien ne soit sélectionné.
2. Dans le panneau Design, repérez **Document**.
3. Choisissez **Réduite** ou **Minimale**.

Les fichiers plus petits prennent plus de temps à enregistrer. **Rapide** enregistre comme le fait Figma, et Figma ouvre les trois.

## Récupérer le travail non enregistré

OpenPencil garde une copie des documents que vous n’avez jamais enregistrés dans un fichier, même après la fermeture de leurs onglets. L’Accueil les liste sous **Travail non enregistré** : ouvrez-en une pour continuer à travailler dessus, ou choisissez **Supprimer** pour effacer la copie.

Les copies restent sur cet ordinateur, dans ce navigateur ou cette application, et ne remplacent pas l’enregistrement. Pour ne plus les conserver, désactivez **Conserver automatiquement le travail non enregistré** dans **Paramètres → Général → Récupération**.
