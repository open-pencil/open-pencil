# ToolbarItem

`ToolbarItem` udostępnia state aktywności i obsługuje wybór jednego narzędzia.

Użyj go wewnątrz `ToolbarRoot`, jeśli potrzebujesz własnego button, ale chcesz zachować wspólną logikę wyboru tool.
