- The library sync probe tracks each remote manifest by its own version (etag), so a publish landing mid-probe can never wedge the mirror on a stale manifest; a library revision pull no longer rolls the mirror's `latest` row back to an older revision when a concurrent publish moved it forward; flag-derived needs (update review, selective publishing) survive retries, backoff, and remote rebuilds; enabling a library the mirror never listed reports not-found instead of deadlocking on sync.
- S3 rate-limit responses (HTTP 429) no longer park document and library synchronization permanently; both engines back off and retry as they do for other transient failures.
