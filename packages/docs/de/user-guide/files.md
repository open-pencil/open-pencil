# Öffnen und speichern

OpenPencil öffnet und speichert `.fig`-Dateien, dasselbe Format, das Figma verwendet. Außerdem öffnet es Webseiten und `.pen`-Dateien von pen.dev.

## Ein Dokument öffnen

Drücke <Keys mac="⌘ O" other="Ctrl O" /> und wähle eine Datei oder zieh eine auf das Fenster. Sie öffnet sich in einem neuen Tab.

## Eine Webseite öffnen

<GuideLegend>

<GuideImage name="files/open-url" alt="Der Dialog Von URL öffnen mit einer Adresse und drei Fenstergrößen" />

1. Wähle **Datei → Von URL öffnen…**.
2. Gib die Adresse ein.
3. Wähle die Fenstergröße, für die die Seite gestaltet werden soll.
4. Klicke auf **Öffnen**.

</GuideLegend>

Die Seite wird zu Ebenen, die du bearbeiten kannst. Eine Adresse kann auch zu einem Bild oder einer Designdatei führen.

Die Desktop-App öffnet jede Adresse und führt vorher die Skripte der Seite aus. Bleibt das an einem Cookie-Banner oder einer Anmeldeseite hängen, schalte **Skripte der Seite ausführen** aus. Im Browser lassen sich nur Websites öffnen, die das erlauben, und ihre Skripte laufen nicht.

Zum Abbrechen schließt du den Tab.

## Eine Datei in dein Design einfügen

Wähle **Datei → Platzieren…** oder zieh die Datei auf die Arbeitsfläche. Du kannst Bilder, SVG-Dateien und HTML-Seiten platzieren.

## Speichern

- **Speichern** mit <Keys mac="⌘ S" other="Ctrl S" /> aktualisiert die Datei, die du geöffnet hast. Browser, die nicht in deine Dateien schreiben können, etwa Firefox und Safari, laden sie stattdessen herunter.
- **Speichern unter…** mit <Keys mac="⇧ ⌘ S" other="Ctrl Shift S" /> lässt dich einen neuen Namen oder Ort wählen.

Dateien in anderen Formaten, etwa `.pen`, werden als neue `.fig`-Datei gespeichert, und das Original bleibt, wie es war. Gespeicherte Dateien lassen sich in Figma öffnen.

## Eine Datei verkleinern

1. Klicke auf eine leere Stelle der Arbeitsfläche, sodass nichts ausgewählt ist.
2. Suche im Design-Panel nach **Dokument**.
3. Wähle **Kleiner** oder **Am kleinsten**.

Kleinere Dateien brauchen länger zum Speichern. **Schnell** speichert so wie Figma, und Figma öffnet alle drei.

## Ungespeicherte Arbeit wiederherstellen

OpenPencil bewahrt eine Kopie von Dokumenten auf, die du nie in eine Datei gespeichert hast, auch nachdem du ihre Tabs geschlossen hast. Die **Startseite** listet sie unter **Ungespeicherte Arbeit** auf: Öffne eine, um daran weiterzuarbeiten, oder wähle **Verwerfen**, um die Kopie zu löschen.

Die Kopien bleiben auf diesem Computer, in diesem Browser oder dieser App, und ersetzen das Speichern nicht. Wenn du sie nicht mehr aufbewahren willst, schalte unter **Einstellungen → Allgemein → Wiederherstellung** die Option **Ungespeicherte Arbeit automatisch sichern** aus.
