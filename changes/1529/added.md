- In the AI chat, type `@` to mention a layer, page, or skill and `/` at the start of a message to run a skill, or an ACP agent's own command; mentions show as chips, in replies too, where the assistant names the layers it touched, and clicking one shows the layer on the canvas. The selection button mentions the selected layers.
- Messages written while the assistant works wait for it instead of being blocked: Enter sends one as soon as the current step's tool calls finish, Alt+Enter waits until all work is done, Escape stops the reply and sends what waits, and Up takes waiting messages back to edit.
