# CanvasSurface

`CanvasSurface` renderuje element `<canvas>` używany przez renderer SDK.

Umieść go wewnątrz `CanvasRoot`, aby SDK zarządzało refs i połączeniem z renderer, a aplikacja — układem i wyglądem.
