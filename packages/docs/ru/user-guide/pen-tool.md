# Инструмент «Перо»

Инструмент «Перо» создаёт векторные контуры на основе векторной сети, совместимой с Figma.

## Включение

Нажмите <kbd>P</kbd>.

## Создание точек

- Один щелчок создаёт угловую точку и прямой сегмент.
- Щелчок с перетаскиванием создаёт точку с рычагами Безье.
- Удерживайте <kbd>Space</kbd> во время перетаскивания, чтобы переместить саму точку, не отпуская кнопку мыши.

Каждая следующая точка добавляет к контуру новый сегмент. Линия предварительного просмотра соединяет последнюю точку с указателем.

## Замыкание контура

Щёлкните первую точку, чтобы замкнуть контур. Замкнутый контур может иметь заливку.

## Открытый контур

Нажмите <kbd>Escape</kbd>, чтобы завершить контур, не замыкая его. Открытые контуры отображаются только обводкой.

## Векторные сети

OpenPencil хранит векторы не как простой список точек, а как векторные сети. Такая модель поддерживает разветвлённую топологию и сохраняется в `.fig` без преобразования.

## Продолжение в режиме редактирования

При активном инструменте «Перо»:

- щёлкните конечную точку открытого контура, чтобы продолжить рисование;
- щёлкните сегмент, чтобы вставить новую опорную точку;
- удерживайте <kbd>Option</kbd> или <kbd>Alt</kbd> и щёлкните опорную точку, чтобы удалить её, если топология это допускает.

Подробнее см. в разделе [Редактирование векторов](./vector-edit).

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Инструмент «Перо» | <kbd>P</kbd> | <kbd>P</kbd> |
| Завершить открытый контур | <kbd>Escape</kbd> | <kbd>Escape</kbd> |

## Советы

- Чем дальше вы перетащите указатель при создании точки, тем длиннее будут рычаги Безье.
- Заливку, обводку и эффекты можно изменить на панели свойств.
