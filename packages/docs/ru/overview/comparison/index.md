# Сравнение альтернатив Figma

Команды уходят с Figma по разным причинам: чтобы владеть своими файлами, работать офлайн или на Linux, разместить собственный сервер, самим выбирать ИИ или перестать платить за каждое место. Инструменты ниже отвечают на эти потребности по-разному. Таблица составлена по документации каждого продукта на ноябрь 2026 года; подробные сравнения — по ссылкам.

|                                  | Лицензия        | Платформы                           | Файлы Figma                       | Офлайн                  | Своё размещение | ИИ и агенты                               |
| -------------------------------- | --------------- | ----------------------------------- | --------------------------------- | ----------------------- | --------------- | ----------------------------------------- |
| **OpenPencil**                   | MIT, Apache 2.0 | macOS, Windows, Linux, веб          | Открывает и сохраняет `.fig`      | Да                      | Да              | Встроенный помощник, MCP-сервер, CLI      |
| [Penpot](./penpot)               | MPL 2.0         | Веб                                 | Через плагин, запускаемый в Figma | Нет                     | Да              | MCP-сервер                                |
| [Lunacy](./lunacy)               | Проприетарная   | macOS, Windows, Linux, веб          | Открывает `.fig`                  | Да                      | Платная лицензия | ИИ-чат, MCP-сервер                       |

Прочерк означает, что в документации продукта об этом не сказано.

## Для чего каждый из них

- **OpenPencil** — редактор дизайна, который продолжает работать с файлами Figma: открывает и сохраняет `.fig`, работает офлайн на всех настольных платформах и создан для управления ИИ и скриптами. Cloud необязателен, и его можно разместить у себя.
- **[Penpot](./penpot)** — самая зрелая открытая платформа для дизайна: веб-приложение с собственным форматом, прототипированием и сервером, который можно разместить у себя.
- **[Lunacy](./lunacy)** — бесплатный настольный редактор с закрытым кодом от Icons8 с большой встроенной библиотекой графики.
- **[Grida](https://grida.co)** — открытый холст для дизайна, изображений и слайдов на раннем этапе разработки.
- **[Graphite](https://graphite.art)** — открытый редактор векторной и растровой графики на основе графа узлов, для иллюстраций и процедурной графики, а не для дизайна интерфейсов.
- **[Quant-UX](https://quant-ux.com)** — открытый инструмент для прототипирования и юзабилити-тестирования.
- **[Pencil](./pencil)** и **[Paper](./paper)** — коммерческие инструменты дизайна, созданные для работы с ИИ-агентами для программирования.
