# useLayout

`useLayout()` stellt Zustand und Aktionen für Flex oder Grid, Breiten- und Höhenmodus, Innenabstand, Ausrichtung und Rasterspuren bereit.

```ts
const {
  isGrid,
  isFlex,
  widthSizing,
  heightSizing,
  setAxisSizing,
  updateAxisSize,
  commitAxisSize,
} = useLayout()
```
