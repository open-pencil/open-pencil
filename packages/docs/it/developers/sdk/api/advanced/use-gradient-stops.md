# useGradientStops

`useGradientStops(fill, onUpdate)` gestisce il punto attivo, il tipo di gradiente, il trascinamento dei punti e le modifiche a posizione, colore e opacità.

Usa il composable per creare un editor di gradienti personalizzato senza reimplementare questa logica.
