# Alternative a Figma a confronto

I team lasciano Figma per motivi diversi: per possedere i propri file, lavorare offline o su Linux, ospitare il proprio server, scegliere la propria AI o smettere di pagare per postazione. Gli strumenti qui sotto rispondono a queste esigenze in modi diversi. La tabella riflette la documentazione di ciascun prodotto a novembre 2026; segui i link per i confronti dettagliati.

## A cosa serve ciascuno

- **OpenPencil** è un editor di design che continua a lavorare con i file Figma: apre e salva `.fig`, funziona offline su ogni piattaforma desktop ed è pensato per essere guidato da AI e script. Cloud è facoltativo e si può ospitare in proprio.
- **[Penpot](./penpot)** è la piattaforma di design open source più affermata: basata sul web, con un formato proprio, prototipazione e un server che puoi ospitare.
- **[Lunacy](./lunacy)** è un editor desktop gratuito e closed source di Icons8 con un’ampia libreria grafica integrata.
- **[Grida](https://grida.co)** è un canvas open source per design, immagini e slide, in una fase iniziale di sviluppo.
- **[Graphite](https://graphite.art)** è un editor vettoriale e raster open source basato su un grafo di nodi, pensato per illustrazione e grafica procedurale più che per il design di interfacce.
- **[Quant-UX](https://quant-ux.com)** è uno strumento open source per prototipazione e test di usabilità.
- **[Pencil](./pencil)** e **[Paper](./paper)** sono strumenti di design commerciali pensati per lavorare con agenti di programmazione AI.
