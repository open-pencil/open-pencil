# Benutzerhandbuch

So gestaltest du in OpenPencil, geordnet nach dem, was du tun möchtest. Neu hier? Fang mit [Erste Schritte](/de/getting-started) an.

::: tip Tastenkürzel
Einige Seiten zeigen die Tastenkürzel für deine Tastatur, die du am Ende der Seitenleiste umstellen kannst. Die übrigen verwenden Mac-Tasten: <kbd>⌘</kbd> ist unter Windows und Linux <kbd>Ctrl</kbd>, <kbd>⌥</kbd> ist <kbd>Alt</kbd> und <kbd>⇧</kbd> ist <kbd>Shift</kbd>.
:::
