# Фигуры

На нижней панели инструментов находятся инструменты для создания фигур, фреймов и секций. Выберите инструмент, затем щёлкните и перетащите указатель по холсту.

## Инструменты

| Инструмент | Клавиша | Результат |
|------------|---------|-----------|
| Прямоугольник | <kbd>R</kbd> | Прямоугольник |
| Эллипс | <kbd>O</kbd> | Эллипс |
| Линия | <kbd>L</kbd> | Линия |
| Фрейм | <kbd>F</kbd> | Контейнер для других объектов |
| Секция | <kbd>S</kbd> | Контейнер верхнего уровня, принимающий пересекающиеся соседние объекты |

## Дополнительные фигуры

В раскрывающемся меню фигур доступны:

- **Многоугольник:** по умолчанию треугольник с тремя сторонами;
- **Звезда:** по умолчанию звезда с пятью вершинами и внутренним радиусом 0,38.

Отдельных сочетаний клавиш для многоугольника и звезды нет.

## Рисование с ограничениями

Удерживайте <kbd>Shift</kbd> во время перетаскивания:

- прямоугольник станет квадратом;
- эллипс станет кругом;
- линия будет привязываться к углам 0°, 45° и 90°.

## Свойства фигуры

Выделите созданный объект и откройте вкладку «Дизайн» на панели свойств.

### Заливка

- **Сплошной цвет:** выбор цвета в HSV или шестнадцатеричное значение;
- **Градиент:** линейный, радиальный, угловой или ромбический с редактируемыми точками;
- **Изображение:** файл изображения в качестве заливки.

### Обводка

- **Толщина:** общая или отдельная для верхней, правой, нижней и левой сторон;
- **Цвет:** сплошной цвет с прозрачностью;
- **Выравнивание:** внутри, по центру или снаружи; обрезка соответствует поведению Figma;
- **Концы:** отсутствуют, круглые, квадратные или со стрелкой для открытых контуров;
- **Соединения:** острые, скошенные или круглые;
- **Штрихи:** длина штриха и промежутка.

### Скругление углов

Скругление доступно для прямоугольников, фреймов, компонентов и экземпляров. Включите независимые углы, чтобы настроить каждый отдельно.

### Эффекты

- **Внешняя тень:** смещение, радиус размытия, распространение и цвет;
- **Внутренняя тень:** те же параметры внутри фигуры;
- **Размытие слоя:** размывает весь объект;
- **Размытие фона:** размывает содержимое за объектом;
- **Размытие переднего плана:** размывает содержимое перед объектом.

Нажмите **+**, чтобы добавить эффект. Строку эффекта можно раскрыть для настройки, а значок глаза включает и отключает его.

## Фреймы и секции

**Фрейм** — контейнер для других объектов. Перетащите фигуру внутрь фрейма, чтобы изменить её родителя. Фрейм может обрезать содержимое, но по умолчанию эта настройка отключена. Фреймы также поддерживают [автоматическую компоновку](./auto-layout).

После выбора инструмента «Фрейм» на панели «Дизайн» появляются сворачиваемые группы заготовок для телефонов, планшетов, компьютеров, презентаций, часов, бумаги, социальных сетей, ресурсов Figma Community и устаревших устройств. Заготовка создаёт именованный фрейм в центре области просмотра, после чего OpenPencil возвращается к инструменту «Выделение». Если фрейм уже выделен, меню заготовок изменит его размер, не меняя имени.

**Секция** — контейнер верхнего уровня. При рисовании она автоматически принимает пересекающиеся соседние объекты. Секции помогают разделить большой холст на смысловые области. Подпись секции можно перетаскивать.

## Сочетания клавиш

| Действие | macOS | Windows / Linux |
|----------|-------|-----------------|
| Прямоугольник | <kbd>R</kbd> | <kbd>R</kbd> |
| Эллипс | <kbd>O</kbd> | <kbd>O</kbd> |
| Линия | <kbd>L</kbd> | <kbd>L</kbd> |
| Фрейм | <kbd>F</kbd> | <kbd>F</kbd> |
| Секция | <kbd>S</kbd> | <kbd>S</kbd> |
| Квадрат или круг | <kbd>Shift</kbd> + перетаскивание | <kbd>Shift</kbd> + перетаскивание |

## Советы

- Секция может находиться только на верхнем уровне, а не внутри фрейма.
- Для адаптивных интерфейсов используйте фреймы с [автоматической компоновкой](./auto-layout).
- Отдельные фигуры и группы можно [экспортировать](./exporting) через панель свойств или контекстное меню.
