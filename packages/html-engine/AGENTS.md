# HTML engine

Blitz compiled to WebAssembly with a TypeScript host. The Rust crate in `crate/` captures; `src/` loads the module, answers its requests, and validates what it returns. Depends on nothing in the workspace; Core turns captures into styled documents.

- The module and its host share a raw ABI: strings and bytes cross as (pointer, length) through `alloc`/`dealloc`, and results come back through one output buffer read with `output_ptr` (`src/engine.ts`).
- Keep wasm-bindgen out: Blitz's `web-time` pulls in imports that no capture calls, and the host binds them to functions that throw with their name (`unboundImports` in `src/engine.ts`).
- Every export the host calls is listed in `EXPORTS`, which `engineExports` checks the module has when it loads (`src/engine.ts`).
- Every JSON shape the host reads from the module has its Valibot schema in `src/schema.ts`, which `layout` validates against (`tests/engine.test.ts`).
- The engine fetches nothing: Blitz's requests queue in the crate, the host answers each with bytes or `fail`, and `layout` pumps until none is left. A stylesheet in `<head>` blocks rendering until it is answered, so a failed request is answered with empty bytes rather than dropped, and each request gets a deadline and an `AbortSignal`, so one that never settles cannot hold the layouts queued behind it. Raster images are answered with an SVG stand-in of their size, and the capture reports what they really were (`tests/engine.test.ts`).
- `bun run build:wasm` (`scripts/wasm.ts`) rebuilds the module only when the crate, the root `Cargo.toml` and `Cargo.lock`, or `rust-toolchain.toml` change, and writes their hash beside it; CI's `setup-bun` action caches `wasm/` by the same files, so a job compiles Rust only when they change; a current module is checked without Cargo, so only a rebuild needs Rust.
- Before pushing Rust changes, run what CI runs: `bun run check:rust` (rustfmt, clippy with warnings denied for wasm32 and the host) and `bun run check:licenses` (`cargo deny`, allowlist in `deny.toml`). The release writes the module's third-party notices into `wasm/` before packing (`notices` in `tools/release/release-packages`), accepting the licenses `deny.toml` allows, and refuses to pack the package without them.
- Blitz is pinned to a git commit in `crate/Cargo.toml`; fixes to Blitz, Stylo, Taffy, or Parley go upstream, not into a vendored copy here.
