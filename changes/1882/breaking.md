- The reference AI relay is now the services server, finishing the rename OpenPencil services started: its command is `openpencil-services` (`node services.mjs` in the image and `dist-standalone`), it reads `OPENPENCIL_SERVICES_CONFIG` and `OPENPENCIL_SERVICES_UPSTREAM_KEY` instead of `OPENPENCIL_AI_RELAY_*`, and the example configuration is `openpencil-services.example.toml`. Its tables and migration history move from `ai_relay_*` to `services_*` on its next start, with nothing to do by hand.
- Billing and operators set Cloud entitlements per account: `PUT /api/internal/accounts/:userId/entitlements` replaces `PUT /api/internal/workspaces/:workspaceId/entitlements`, and the `entitlements` command takes `--account <user id>` instead of `--workspace <id>`. Existing workspace entitlements move to each workspace's owner on upgrade.
