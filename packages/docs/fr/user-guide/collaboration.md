# Collaboration

Partagez un fichier, et toutes les personnes qui ont le lien le modifient avec vous en même temps. Vous voyez les curseurs et les sélections de chacun, ainsi que les agents IA que chacun utilise. Les personnes se connectent directement entre elles, sans compte.

Pour des fichiers hébergés sur un serveur, avec connexion, partage et historique des versions, utilisez [OpenPencil Cloud](/cloud/).

## Partager un fichier

1. Cliquez sur **Partager** en haut à droite.
2. Cliquez sur **Partager ce fichier**. Un lien vers la salle du fichier est copié.
3. Envoyez le lien aux personnes avec qui vous voulez travailler.

Toute personne qui a le lien peut rejoindre la salle. Le lien est difficile à deviner : seules les personnes à qui vous l’envoyez peuvent donc trouver la salle.

## Rejoindre un fichier partagé

Ouvrez le lien. Vous pouvez aussi coller le lien, ou simplement l’identifiant de la salle, dans **Rejoindre** du panneau de partage, ou dans **Rejoindre une salle…** sur l’Accueil. Le fichier s’ouvre dans un nouvel onglet : les fichiers que vous avez déjà ouverts ne changent pas. Dans le navigateur sur un ordinateur, **Ouvrir dans l’app de bureau** l’ouvre dans l’app.

Vous rejoignez la salle sous un nom inventé, comme *Teal Fox*. Changez-le dans le panneau de partage ou dans les Paramètres ; il est utilisé dans toutes les salles.

## Où se trouve le fichier

Aucun serveur ne conserve le fichier : il se trouve sur les ordinateurs des personnes qui sont passées dans la salle. Une salle ne s’ouvre donc que lorsque l’une d’elles est en ligne. En attendant, l’onglet indique qu’il attend, et le fichier s’ouvre dès qu’une personne qui l’a rejoint la salle. Une salle où vous êtes déjà allé s’ouvre immédiatement à partir de votre propre copie, et vos modifications se synchronisent quand les autres reviennent.

Les modifications de différentes personnes fusionnent, même quand deux personnes déplacent ou réordonnent des calques en même temps. Tout le monde doit avoir une version récente d’OpenPencil pour être dans la même salle.

**Quitter la salle**, dans le panneau de partage, met fin à votre participation. Le fichier reste ouvert sous forme de copie que vous pouvez enregistrer.

## Discuter en appel vocal

Dans une salle, **Démarrer un appel vocal**, en haut de la fenêtre, lance un appel, et les autres voient **Rejoindre l’appel vocal**. Son menu permet de couper votre micro et de choisir le microphone et les haut-parleurs. Le navigateur ou votre système demande une fois l’accès au microphone.

## Suivre quelqu’un

Cliquez sur l’avatar d’une personne en haut de la fenêtre pour voir ce qu’elle voit. Votre vue suit la sienne, encadrée de sa couleur. Cliquez à nouveau sur l’avatar, appuyez sur <Keys mac="Esc" other="Esc" /> ou déplacez-vous vous-même pour arrêter.

## Voir ce que font les agents IA

Chaque agent IA apparaît sous forme de curseur sur les calques qu’il lit et modifie, avec un nom comme *Fern*. Dans une salle, le curseur d’un agent a la couleur de la personne qui l’utilise.

- L’avatar d’une personne indique le nombre d’agents qu’elle utilise. Survolez-le pour voir ce que fait chacun et où, puis cliquez sur **Suivre** pour garder son travail en vue.
- Vos propres agents sont suivis pendant qu’ils travaillent. Désactivez cela avec le bouton cible en haut du chat IA.
- Cliquez sur l’un de vos agents dans la liste de votre propre avatar pour le renommer.

Seuls le nom d’un agent, son modèle, ce qu’il fait et l’endroit où il travaille sont partagés, jamais vos messages ni ses réponses.
